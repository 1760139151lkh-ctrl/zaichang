## 一、SwiftUI 级可打断弹簧动效与时间轴动力学

手感来自及时响应、连续位置与可接管性。拖动期间直接跟手，松手归位优先用可保留速度的弹簧；颜色、透明度和短揭示可用缓动，匀速过程可用线性。不能把阻尼、外力和约束下的界面动画统称为动量守恒：

### 1.1 三组候选弹簧参数（需按真实对象调校）

以下是设计候选，不是现有默认或统一完成时长；当前 `use-spring.ts` 默认280/30/1，实测行程、中断与边界后再采用。
```typescript
export const SPRING_TOKENS = {
  // 1. 轻巧微交互（按钮按压、胶囊点选、便签微翘、小图钉亮起）
  micro: { stiffness: 420, damping: 28, mass: 0.8 }, // 约 160ms–200ms，清脆利落，零拖沓

  // 2. 空间退让与分屏展开（工作台滑入、伴读角色侧身让位、书签托盘弹出）
  spatialYield: { stiffness: 280, damping: 26, mass: 1.0 }, // 约 280ms–340ms，柔和沉稳，无过冲眩晕

  // 3. 拖拽吸附与落座（角色换锚点落座、日程块磁吸落位、路线口袋收拢）
  docking: { stiffness: 320, damping: 24, mass: 0.9 }, // 具有饱满的物理阻尼缓冲感
};
```

### 1.2 随时可打断与初速度无缝继承（Instant Interruption & Velocity Handoff）
- 当工作台正在向右滑入或角色正在移动时，若用户指针按下并向反方向拖动，**必须立即中止正在运行的过渡，直接继承当前位置与即时速度跟随光标**；
- 严禁“等动画播完才响应用户操作”，严禁“瞬间跳回起点造成画面闪现”。

### 1.3 从 Gemini 动态视频参考到前端活代码的转译映射
| Gemini Omni Flash 动态视频参考 | 前端活代码实现机制 | 交互与物理表现 |
| :--- | :--- | :--- |
| **3–5 秒无缝呼吸微循环** | CSS `@keyframes` + SVG 骨骼滤镜 + Canvas 粒子 | 伴侣发丝微动、胸口呼吸起伏、窗外光斑浮动，可暂停与静态替代；CPU、解码、内存和耗电在目标设备实际测量 |

## 二、全场景五阶段直接操作契约（The 5-Stage Direct Manipulation Contract）

全站所有拖拽（拖角色、拖日程、拖书签、拖滑块），必须严格实现以下五阶段完整闭环，并确保**键盘焦点与正在编辑的输入框草稿 100% 零丢失**：

| 阶段 | 状态名称 | 视觉、物理与业务行为规范 |
| :--- | :--- | :--- |
| **Stage 1** | **接收 (Pickup)** | 按下瞬间元素轻微浮起（`scale(1.025)` + 柔和暖色投影加深），原位置保留半透明淡化锚点，光标切换为 `grabbing`。 |
| **Stage 2** | **试放 (Preview)** | 移动到目标区域时，邻近元素以弹簧弹性向两侧推开让位，展示半透明幽灵块（Ghost Slot）；**注意：试放阶段绝不写入后端 SQLite 数据库**。 |
| **Stage 3** | **确认 (Commit)** | 松手落在合法槽位，元素沿弹簧曲线落入提交中的位置，触发原Owner带 `expectedRevision` 的提交；真实成功回执到达才表现为已保存。动画落稳不替事务确认。 |
| **Stage 4** | **取消 (Cancel)** | 按下 `Esc` 或拖出有效区域松手，元素沿阻尼轨迹平滑飞回原位，目标区元素弹性合拢，正在输入的文字草稿纹丝不动。 |
| **Stage 5** | **异常恢复 (Recovery)** | 确认未生效或版本冲突时保用户草稿、比较当前版本并原地调整；结果未知先核原动作，不盲重发，也不先回弹宣称已撤销。给出具体事实和可继续入口。 |

## 三、《新建 Text Document (4).txt》七大王牌创意代码化落地规程

### 1. 你说“这里”，她真的知道是哪里，看错了也能自然改过来（AI Pointer）
- **交互分镜**：
  - 用户在讲义中划选或手指点在某个积分等号旁，说：“我就是不懂这里怎么过去的。”；
  - 目标公式两侧浮现温润手绘质感的淡金铅笔括号（`PencilBracket`），解释从公式右侧自然展开；
  - 解释中提到变量 $u(t)$ 时，讲义上的对应变量 $u(t)$ 泛起柔和高光脉冲；
  - 若她理解成上一行，用户轻点下一行或把解释旁边的小锚点轻轻挪过去，伴侣自然改口：“哦，你说的是下一行呀，我刚才看岔了～”并即时调整解释；
- **前端实现**：
  - 设计中的 `AIPointerLayer` 消费原Owner引用与当前有效锚点，页码和屏幕矩形是视图投影，不能单靠 `{ spanId, page, rect }` 跨页定位；
  - 同一次共同注意可含 A/B 两个目标及它们的关系；伙伴指针与用户光标区分，提及符号时只强调真对应，注意离开后自然退去；
  - 移锚/点下一行经现有Bridge进入当前主循环的协作上下文，旧解释依据及时失效；模型沿新指向改判，而非只让前端移动高亮、回复仍讲旧内容。这里的组件名与协作字段是设计目标，须映射现有类型；
  - Stage 01 交付真实理解与纠偏链，Stage 08 完整打磨纸面及跨域对应，Stage 12 检查错误目标迟到的连续体验。

### 2. 让过去那张纸，和今天这张纸“认出彼此”（Drawing Paper Overlay）
- **交互分镜**：
  - 几天前画过的平面旋转几何草稿，在今天学到复指数 $e^{it} = \cos t + i\sin t$ 时，伴侣在桌角推入旧草稿的一角：“你之前画的那圈箭头，能和这里叠起来哦”；
  - 用户按住纸角，旧草稿如一张半透明描图纸（Tracing Paper Overlay，`mix-blend-mode: multiply; opacity: 0.85`）平滑覆盖在当前公式上方；
  - 几何旋转轨迹与复数表达式位置严格对齐，两层含义一目了然；松手后旧纸轻轻卷起退回桌角；
- **前端实现**：
  - 设计中的 `TracingPaperOverlay` 由真实旧稿/当前稿、成对语义锚点及配准依据驱动；按住揭示、松开复原，也有点击/键盘等价操作。透明度与纸张弹性只是呈现；
  - 几何旋转、复数和坐标表达分别讲清对应条件，不把公式排版位置硬配准成同一数学对象。无法叠放时并排指向，仍保留联系和差异；
  - 计划/实跑、初稿/改稿、最初概念图/完整模型都支持这种相认。用户能否定一条联系，模型重新解释，不为了“成长故事”编造关系；
  - Stage 03 负责相关原经历与条件，Stage 04 负责版本/映射/比较组恢复，Stage 07/08 负责实际路线与纸面交互。

### 3. 两个人接着动同一个对象（Turn-Taking Living Canvas ·《Florence》级手势交接）
- **交互分镜**：
  - 在几何图、函数曲线或日程沙盘上：你画一条主线，她补一条虚线辅助线；你拖动端点，她补的辅助线保持正交关系动态跟随伸缩；
  - 你擦掉某个前提，依赖它的线条自然淡化退开；你重新拿起笔，她的光标与提示主动让出位置；
  - 整个过程无需多言，共同操作的对象本身就是对话。
- **前端实现**：
  - 参与重心可用 `user_active / companion_assisting / shared_rest` 描述，但还须有递出、试改、部分接受、撤回、冲突和停点；不能拿三个状态代替完整交接；
  - 草稿线、路线候选、安排调整、段落建议和作品参数回到各自Owner的具体局部操作，保作者、基准版本与依赖。只接受一笔，其余仍是提案；用户修改前提，依赖它的建议重新求值；
  - 手势“递—摊—接—收”跨对象有亲缘感，实际内容不等动作完成才可用。Stage 04 建局部操作基础，Stage 07–10 完成各域共同操作，原有各阶段八人职责不减少。

### 4. 随身带着“刚才那件事”，跨页换形态（Traveling Context）
- **交互分镜**：
  - 讨论一段证明时，收起对话窗，浮动入口不变成死头像，而是留下一小角微卷纸张，露出刚才讨论的数学符号；
  - 规划路线时收起，紧凑形态上带着一段发光路线弧线；
  - 跑步时收起，可由声音、可扫视小状态与可选边缘微光承接；暂停、结束和返回仍能找到；
  - **跨页面切换时，同一对象与有效动作接续，绝不每次重置成僵硬迎宾立正姿态**。起终点和接触关系仍成立才顺势完成递纸；若用户落笔、目标失效或新布局不兼容，就从当前姿态自然收手，不能强播旧动作；
  - 载体记录当前对象组、两纸比较关系、未完问题和停点；入口稳定，展开仍回原输入与对象。悬浮球保留为可比较方案，不把“一种形式先做通”当成所有形式已交付。

### 5. 共同经历留在对象上，长出你们自己的小记号（Living Relational Tokens）
- **交互分镜**：
  - 上次对紫金港某条小径说过：“这里太窄了，我不喜欢”，地图该路段留下一枚极轻的浅金小钉子（点击展开当时对话上下文）；
  - 共同起过名字的难解题卡点（如“小怪兽”），保留当时手绘的歪星星或问号标记，成为独家默契；
- **前端实现**：
  - 设计中的 `RelationalTokenLayer` 挂载在原对象视图，平时克制，鼠标靠近、键盘聚焦或明确点选均可展开；不靠仅hover承担唯一入口；
  - 外观既可选预设，也可引用用户原笔迹、图形与可编辑形状的版本，含义连回原话或作品，不复制成另一份永久私人正文；
  - 记号和“为何留在这里”可以随路线到日程、随旧稿到新题。改名、移除或更正原因要到达这些投影；Stage 03/04 建来源与关联，Stage 07/08/10 完成实际表现。

### 6. 允许你只是轻轻叫她一下（Gentle Check-In / "嗯？"）
- **交互分镜**：
  - 用户点击伴侣头像，或在窗口边沿轻轻敲击两下；
  - 伴侣停下手中正在翻看的乐谱或书页，清澈地看过来：“嗯？”；
  - 若用户接着打字，她倾听；若没有继续，她留一段自然可变的等待再继续自己的事，时长按人物、情境和新输入调校，不强定三秒；
  - **零弹窗、零建议列表、零心理分析过度反应**。

### 7. 她的反应能接住你上一个动作，小小的玩笑也能继续（Chained Playful Continuity）
- **交互分镜**：
  - 桌角有一张便利贴，用户故意拨歪一点，她顺手扶正；
  - 用户又拨歪，她这次先看你一眼；
  - 用户再拨歪，她停了一下，嘴角微扬把自己的铅笔也摆歪了；
  - 打断她的唠叨时，她放下手：“好啦，刚才那句不算数～”；
- **前端实现**：
  - 设计中的短期微互动记录保留与当前来往有关的事件、因果和已实际表达的反馈，不固定只存三轮，也不把每次拨动永久写成人格画像；
  - 本地先响应按下/推回/落笔，必要语义沿同一主循环让角色选择下一步。三次拨歪是示例，不是固定台词分支；可以接招、变化、停住，过去喜欢的动作在合适间隔偶尔呼应；
  - 不在正在编辑的正文上制造玩笑，用户转身工作立即让位，失效笑点不排队补播。角色有自己的眨眼、翻书等生活，不强迫每个闲置动作都绑定业务回执；
  - Stage 01 有轻唤与角色理解，Stage 06 完成受控动作与声景，Stage 10 打磨因果玩笑和自然收束，Stage 12 实际体验连续性。

## 四、伴跑系统极简边缘微呼吸与生活贯穿（Ambient Cadence Halo）

运动时保护当前内容：边缘微光可作低注意力状态，同时保留稳定召唤入口和可展开的暂停、结束、记录。用户需要时可有小状态窗或托盘，不能用一条边缘光替代全部信息与控制：
- **视觉规格**：窗口四周边框带有 `2px` 柔和高斯发光边，随步频（SPM）同步呼吸脉动；步频快时微光微快温润，步频平稳时安详如晨露；
- **扫视交互**：鼠标移近窗口边缘，极淡墨色温润浮现“172 SPM · 5'15" · 2.8 km”，移开瞬间自然融回背景，100% 零视野遮挡、零工作打扰；
- **时空归来贯穿**：跑完回到桌面，路上随口说的半句话已经贴在微积分讲义旁边：
  **“路上想到的那句，放这里了。”**

## 五、文案消融测试与彻底清零工程黑话（Copy Ablation & Human Voice）

吸收殿堂级设计法则：**“The best interfaces need almost no words because the layout does the explaining.”（最好的界面几乎不需要多余解释，因为布局自己会说话。）**

### 1. 三秒文案消融测试（The 3-Second Ablation Test）
- 检查页面上的每一行说明小字、空状态提示与副标签：
  **如果拿掉这行字，用户仅凭卡片布局、手账纸纹与光影依然一眼看懂怎么用，立刻删掉它！**
- 坚决删除：“在此处输入消息”、“这是您的日程列表”、“点击下方按钮切换主题”等工程废话。

### 2. 工程黑话与调试词汇彻底清零清单
日常主内容避免把下列内部状态当作劳动收条；必要业务数字、进度、连接设置、来源说明与用户主动打开的诊断保留准确表达，不按关键词一刀切删能力：
- ❌ `已接通` / `未接通` / `待验证` / `返回未接入` / `虚线接入待核` / `模拟数据`
- ❌ `3/3` / `Step 1 of 4` / `覆盖率 100%` / `队列处理中`
- ❌ `SceneSnapshot` / `PresentationView` / `OpenUI` / `CAS` / `Revision` / `BGE` / `Hermes` / `Luna` / `Sidecar`
- ❌ 任何 SHA-256 哈希串、内部 UUID 或原始 JSON 字段名。

### 3. 角色化温和微文案（Persona-Infused Microcopy）
空状态与异常提示必须符合当前角色的知己口吻，且包含**事实 + 影响 + 顺手下一步**：
- ❌ 错误示范：`[Error 409] Agenda revision mismatch, commit rejected.`
- ✅ 正确示范（祥子口吻）：`刚才那段日程好像刚刚变动过，我先把新方案停在预览区了，你看一眼要不要放在下午四点后？`
