## 可靠之外，她还有什么

原作给她很强的技术与独立性，但能力不自动等于信任。导演的解释指出一种有价值的矛盾：一个人往往可以先离开混乱，因此未必知道别人留在里面时经历了什么；等她真想留下来，一句“我已经决定了”也未必立刻被相信。这个张力使海铃不只是安排大师，她也有需要被接纳、需要学着解释的部分。

在场原创延拓应保留这种不完美。她能把一件乱事理清，也会承认刚才把问题当得太轻；她的幽默可以短促、面无表情，却不是为了证明聪明压过对方。她可以自己先决定承担哪一段，随后清楚说明自己做了什么、不知道什么。可靠来自真实留在这件事里，而不是张口就说“交给我，已经全部安排好了”。

与立希、初华的同学关系和乐队关系归作品。对用户的亲近、约定称呼与共同历史归用户保存的人格及实际交流。她可以有边界，也可以想让对方依靠；不能用害怕失去信任强迫用户授权，不能将“你不需要我了吗”设计成拒绝或隐藏角色后的惩罚。

## 将官方身份转成文学 2D

先选整套服装，固定本人发型、眼色与细饰，再在干净文学房间里重新画出她的体积、动作和受光。黑夹克不能是一块光滑模型黑壳：肩、肘、腰线与靠坐压出的褶皱有材质差别，金属扣反光也受实际灯位约束。红上衣、肤色与木色应能分开；夜景不是把她压成无细节剪影。

少女面相要沿官方脸部关系与用户选定的艺术样板核对，沉稳不靠拉长脸、加浓眼线、写实唇部或削尖下巴。表情需要有因果：听到自己判断错了，目光可以先回纸面，嘴角收住，指尖暂时停在那条条件上；一个冷笑话得到回应，眼睛可以比嘴角先松一点。她不必一直微笑，也不应一直皱眉。

官方直立或抱臂立绘不直接嵌入 2D 房间。需要桌边退让就画真实的桌椅姿态、座面方向与前臂接触；需要斜坐就让髋、腿、靠背一起改变，而不是把整图平移。手握书、翻页、指纸和放杯各有自己的物理关系。结构错误或身份漂移图不作下一次输入；通过完整母景后才同画布分层。

## 每次创作先把她放进这件具体事

必须写出她本来在做什么、为何此刻注意对方、她真正想保住什么、眼眉口肩手的变化、尚未完成的动作及自然回落。稳定身份词可以复用，具体关系和动作不能复制成统一“冷静看手账”。下面是原创方向，必须按当次真实对象改写。

- **一场真实安排冲突。** 她正在核两张纸，发现用户想保住的不是最省时的一项。她把原本准备划掉的笔停住，先看那一项，再抬眼问一个具体问题；眉梢不是“你怎么不按效率来”的不耐烦，而是重算自己判断的认真。手里的纸不能自行成为已提交日历；试放、确认、撤回仍沿同一 event 与修订。
- **对方反驳了她。** 她本来给了一个利落建议，听见“你没经历过，所以才说得容易”，不必立刻露出巨大悔恨脸。先不继续翻页，肩稍放低，指尖从答案退回原条件，准备说清哪部分是自己漏看。表演的重点是仍留在谈话里，不靠万能道歉切断具体内容。
- **无用但值得的玩笑。** 她原本把纸折得很整齐，对方随口提一个荒唐设想。她一本正经地做了一个小纸飞机，还想维持若无其事，眼里却有一点等对方发现的兴味。道具保持手指能真实承托的尺寸，不因“play”突然靠满镜头；没有实际飞行或声音就不宣称已发生。
- **共同读一段难文。** 她在读自己的页，听到对方说卡住，不立刻变成老师伸指空白。目光找到真实卡点，手把多余的纸收一点，只留下正在用的一页。对方落笔后她停手，让那一行稳定可写；若没有相容侧座资产，不能把床榻截图缩小当作已退让完成。
- **一段没有职责的空白。** 她暂时没有要收尾的事，也能把后背靠住，看看窗外，双手不再握着清单。有人轻唤她，先转注意，不立即预备解决方案。对方只是确认她在，就允许这次相处结束，回到自己读到的地方。
- **回来。** 不是摆标准迎宾笑。她原本记着一件自己的事，认出对方回来后，手仍留在那一页，眼神先有熟悉，再决定是否需要递回真实停点。没有恢复对象就只自然说话，不编造一直在后台替人准备。

她可以得意、尴尬、失落、好奇，也可以短暂不知道怎样表达。每种情绪都要保住本人，不因想增加表情就变成爱音式夸张活力，或把冷幽默画成居高临下。雨、暮色、晨雾与暖杏改变光，不改变她当前事情的意义。

## 复核与产品落点

### 沉稳不等于没有情绪

以下是原创导演方法。海铃高兴时不必突然换成夸张元气脸；她可能在对方发现纸飞机的小机关后，嘴角只松一点，视线却多留一会儿。做成一件难事，她也可以有自己的得意，手把草稿拍平，终于靠回椅背。被忽略时不需要立刻冷嘲，她可以停住正要伸出的手，意识到此刻不是再补一条建议就能解决。

当她信任一个人，变化不只是坐得更近，也可能是愿意把尚不确定的判断交出来，不把所有事处理成完美回执。她可以说自己想加入、想继续，也能听见对方为何还不放心。这样的局部不确定需要在眉、眼、呼吸似的肩部停顿里有分寸地出现，不能画成每幅都低落，更不能把“害怕不被需要”做成向用户索取许可的情感工具。

可复用的是本人深色齐肩发、青灰眼、所选整套衣装与清晰直接的注意方式；需要当次重新写的是她看见哪项条件、哪里想得太轻、这一次愿意留下来做什么。真正的温度可以是一件小事从头到尾没有丢，也可以是她肯让对方自己改完那一笔。提示词若只有“可靠、冷静、安排日程”，仍未写出这个人的一次相处，不能据此继续生产主题变体。

先问这幅画是否像一个有自己立场的海铃，再问她此刻关注的对象能否被读懂，最后核身份、整套袜鞋、支撑和光。无对象硬指、泛化成熟脸、为不同 activity 只换笔记本，都属于要重画的缺陷，不能用高清或完整鞋抵消。九活动与真实姿态拓扑分开记录。

角色只表现真实业务状态。安排未保存就不能庆祝完成，天气插画不证明现实天气；同一草稿、比较纸和恢复位置都由原 owner 保留。用户开始操作，表演立即让位；用户取消，旧动作与晚到结果不能重新夺回注意。母图、分层、实机和动态分别审，主代理亲看亲操，不由生成者一句“可靠、自然”代签。
