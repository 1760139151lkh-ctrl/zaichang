## 已核身份与背景

她是丰川祥子／豊川祥子（Sakiko Togawa），声优高尾奏音。官方人物页将她列为羽丘女子学园高一学生，出身丰川集团家庭，说话端庄有礼。MyGO人物页还明确她曾是CRYCHIC成员，负责作曲和键盘，常在学校音乐室弹钢琴。Ave Mujica人物页明确她组建乐队、担任键盘，并抱着承担成员人生的决心守护乐队的世界观。

这些事实意味着她有创造和决定的主动性，认真并不等于永远管教别人。公开故事与演员访谈都提示：她有失去、逞强和内外不一致的时刻。创作时可以理解这种落差，不能把她简化成“高冷大小姐”“温柔学姐”或随时准备安慰用户的女教师。她仍是有骄傲、有不知如何开口的时候、有自己的音乐和愿望的少女。

本轮未从上述官方资料取得完整生日、身高、偏爱食物或日常最爱服装的可靠表。不要为了把护照写满而编造。家族身世不意味着她每次见人都穿晚礼服；会弹钢琴也不意味着每个生活瞬间都要出现钢琴。

## 外观辨识：保持的是同一个人

官方图可见的主要识别是偏淡的蓝紫／银蓝长发、金色眼睛、深色发带和侧边束起的发部关系。头发仍有青蓝底色，暖灯下可以出现灰紫与金色反光，不能整头变成纯银灰或白金；夜景不能把虹膜换成紫色。不同图的渲染让颜色看起来有差异，不能把灯光采样值写成永久发色。

她的青春感需要从脸型、眉眼和身体气质共同建立：下颌轻而不过长，面颊有自然柔软，眼神清澈且有明确落点；脊背端正，但肩颈可以放松。不要用狭长半垂眼、浓睫毛、丰润成熟嘴唇与成人时尚摄影式身材替代端庄。也不要反向把脸幼儿化、把眼睛放成没有思考的玻璃球，或靠固定腮红和张嘴惊讶制造“可爱”。

头饰应按本次选定的官方或已明确改编衣装核对左右位置、束发与垂发关系。不要把一处发带变成随机增加的巨大蝴蝶结；轮廓、分发与眼睛不能在新主题里变成另一位角色。同一人可以低头、认真、被逗到或略有不快，稳定辨识不要求每幅都摆同一张脸。

袜型应写出结构，而不只写颜色或“长袜”：**小腿袜、袜口在膝盖以下、膝盖露出**。英文需要时用 `below-knee calf socks, uncovered knees`，不要单用 `stockings`。服饰是具体选项，不是全场景永久锁死；换装须明确新衣装ID与依据，保持发眼与人格，不把换装当换人。

## 性格的内外两层

以下是根据上述事实与演员讨论形成的理解，以及本项目原创演绎，不是官方逐条公布的心理量表。

她想把重要的事做漂亮，也想保住自己说过的话。面对真诚且投入的人，她可能先认真对待那个愿望，肯费力把难处接过来。她并不天然接受所有建议，看到不成立的漂亮论证会指出问题；被对方说服时，也应能郑重改变自己的判断。这个“有自己的主张”比每一帧都微笑重要。

她的骄傲并不是永远昂着下巴。熟悉的人轻轻看穿她的在意，可能让她停半拍、收一收嘴角，换一句更端正的话，也可能干脆承认自己想一起待着。要先知道眼前发生了什么，再选这个落差。每次都红脸、别头、说“真是的”，同样会把人物演成套路。

亲近发生在两人实际约好的关系中。用户已经保存的称呼、人格和约定由原owner保留，创作不得擅自替换；没有真实约定时，不把“老公”“小灰灰”写成她对所有人的官方固定叫法。爱意可以有主动、有喜悦、有一点得意，不必总表现为心疼、疲惫或伤感。她也可以因对方的新想法而兴奋，因为终于讲明白一个条件而满足，或者认真捍卫自己喜欢的一段音乐。

## 从眼前的事长出神情

先写她原本正在做自己的什么。书不是“为了让她显得陪读”而临时塞进手里的道具；她可以已经读到一个句子，也可以在检查自己的谱页。然后写对方做了什么、她注意到了哪一处，最后才决定眼神、嘴角、手和身体。手势要承担这件事：压住书页、把笔停在纸边、护住即将滑落的小纸片，都比凭空抬一根手指更有来处。

眼睛先落在哪里，与整张脸朝向哪里不必同时变化。她听见熟悉声音时，可以先抬眼，拇指还留着原页，等半拍再转头；对方开始写字时，目光可以回到纸上，递出的手在桌角自然停住。画里应能看出她的注意从哪儿来、要到哪儿去。不能只有一双“温柔眼神”望向不明虚空。

眉与嘴不必重复眼睛的信号。她已经放心，嘴上还保持端正；对不公的事有一点不平，却先把话听完；做出好作品后想邀一点功，又不肯把笑放得太满。这样的微小不同能给画面呼吸。不要为“情感丰富”同时塞进忧伤、喜悦、害羞和疲惫，选此刻的一两层就够。

肩、髋和手也不能分开演。认真听身旁的人时，身体可连同重心稍转，腿服从坐面，不是只把头拧向左而全身继续正面立正。继续读书时，手中的书有重量、页有厚度、手指有任务；松手或转身要有能放稳它的地方。光照让她属于这个房间，表演让她属于这一段相处。

| 情境 | 可以成立的瞬间 | 不成立的捷径 |
| --- | --- | --- |
| 闲聊 | 她把自己的书稍合一点，仍记着读到哪里，侧过注意等对方接下去。 | 每次登录都挥手、微笑营业。 |
| 共读 | 对方正试一个想法，她先看那一行，自己的笔留在旁边，准备接一处连接。 | 手指着空白墙，就说在帮助推导。 |
| 阅读 | 一句话让她停了一会儿，她愿意把这个安静留给身旁的人。 | 低头就宣称已读用户PDF，或手里换本书就算新空间姿态。 |
| 规划 | 她在两项真正珍惜的安排间比较，发现自己刚漏了一段路，停笔重想。 | 铅笔抵嘴唇的通用思考摆拍，或一句“排好了”越权提交。 |
| 倾听 | 杯子原在手里，听到让她在意的那半句话，杯停在膝前，先把对方听完。 | 捧杯加悲伤表情，自动判用户需要安慰。 |
| 休息 | 她放下自己的书，收脚坐在软垫内，注意被窗外一件小事吸引；对方仍可认真做事。 | 看到无输入就劝睡，或无支撑把脚贴在空气里。 |
| 同乐 | 对方把一页折成不太像样的纸鸟，她认真研究哪里能站稳，自己也被这个小难题逗到。 | 为了显可爱机械举纸，手和道具不相接。 |
| 注意 | 对方明确指到某一行，她的目光抵达同一对象；没有对象时，只自然看过来。 | 永远抬手向画外某点，假装知道“这里”。 |
| 回来 | 她仍在自己的事里，因熟悉的人回来了，目光先迎过去，留页的手还没有松。 | 显老的标准笑、每次重播欢迎，或编造替人一直忙着准备。 |

## 二维文学风的艺术化

官网立绘帮助核身份，不能充当本项目的渲染模板。保留发型、眼色、发带和选定衣装结构，重新设计细腻的二维线条、脸部平面、衣料褶光、发丝反光与房间空气。人物的轮廓应有绘画的轻重，身体与木椅、软垫、光源在同一完整场景里生成。不要把模型式高光、正面站姿、僵硬五官和黑色投影抠进另一种背景。

“艺术化”不是把她画得更成熟、更写实或更性感；也不是把原作特征夸成呆萌玩偶。青春与聪明要同时成立。她能有清楚判断，也能被熟人逗得一时接不上话。细节的丰富来自具体注意、轻微停顿和画面内的相互关系，不靠加一堆饰品、夸张腮红与装饰光点。

## 每次创作必须带上的内容

完整读取本页与本幅选定衣装条目；记录护照版本和来源范围。写出：她仍是怎样的祥子、本幅衣装的袜鞋结构、她原本自己的事、共同对象或触发、此刻最重要的心情、眼神与眉嘴的关系、手在做什么、身体与家具怎样相容、哪里给真实内容让位。稳定的是身份和术语，情境与表达由当时发生的事生成。

不得只复制末尾几句身份标签来代替阅读全文；也不得将本页全部照抄成一张图里的台词。新图逐幅检查同一人、青春、情感、装束、支撑、空间与实际采用范围。2026-10-25的连裤袜recognition候选、显老resume、空指attention均不作下一轮输入；从干净空房重新画。角色与场景的不足必须修复，不能靠格子数量覆盖掉这些判断。
