## 现在能做什么

本轮沿原聊天落实“先接住眼前，再按需要深入”。`recall_experience` 让主助手把当前问题交给同一 Hermes 的真实只读子调查，找回当时的经历、理由、例外和后来变化，再形成自己的当前判断。共同商量和陪学继续属于原事项；来信可以承接真实生活片段，好奇邀请应带来一件已经准备好的具体内容。调查中仍可写草稿，有想补的话便从原输入区“补一句”，按新原话接着聊。当前已有正常 Luna 查询、原生画面及原对象／原句续问的限定记录，合成资料、真实校园只读与公开参考数据分开说明；记忆深读、自然相处与各新增界面仍按[各自证据范围](docs/CURRENT_STATUS.md#personal-memory-round7)判断，不扩称全部通过。

使用时仍是直接说话：“我还说不清，你先陪我理理”“上次为什么没选那个，现在有什么不同”“这道题先给一点提示”“今天先停在这里”。这些是交流示例，不是固定口令。助手应按当下的意思选择商量、深读、实际帮忙或安静结束；需要保留起点时沿原事项留下，不要求用户另外维护一套记忆清单。

共同内容也能指着接话：学习纸上的一行、安排中的一段、共写作品的一句，沿原对象带到输入框旁的小引用。已经写的草稿保留，引用可以拿掉，下一句仍可以改变主意；选中不表示赞同、接受方案或形成长期偏好。原题、本人尝试、助手建议、来信和虚构作品保持各自身份。

学习纸已经实际走过安静阅读、点旧行引用、保留原稿、取消后直接接写，以及键盘聚焦旁注再引用的同一条路径。纸上不再常驻一排“问这一行”标签，选中的位置仍留着轻标记；这份实际观察不代替模型理解效果。共同创作的活动身份也已接入原消息和记忆恢复链：作品里的“我”不能变成本人生平，现实中的创作愿望和独立自述仍分别理解，当前这条记忆机制尚未运行模型核验。

有些话可以先在这里试着说。关系表达排练保留本人想表达的意思，由同一个主助手扮演对方的一种可能回应；觉得不像就换，随时停下或整理成一段尚未发出的表达。试说不是已经对外说过，模拟回应也不是对方的真实态度。相应owner、Scene和原输入引用已接源码，当前模型表现与实际画面范围仍见本轮状态。

第三批从 `30dcd8e` 继续，落实[重开后可继续商量的规划意图](docs/research/PERSISTENT_PLANNING_INTENT_2026-10-18.md)：在原事项系统保留带来源的任务、时窗和预算，回读真实日历与动作回执后重新试算。已安排、这次试算与本人完成分开；旧批准与票据不会恢复。后端整合检查后生成两版 GPT Image，沿现有时间带加入安静的续接关系，并实际操作桌面与窄窗。最终审查发现的恢复边界及核查状态见[第三批状态](docs/CURRENT_STATUS.md#personal-memory-round3)，不是新版EXE或移动端发布。

恢复后真正保存时，还会核对本次借用的旧证明；原依据停止使用，相关画面、准备正文和跨回合历史也随之退出，独立材料保留。用户不需要维护这些依赖。

## 系统组成

Electron main 负责本机数据库、凭据、权限、工具和副作用；React renderer 通过有限 Bridge/IPC 显示内容并提出操作。Hermes Python sidecar 使用锁定的上游 `AIAgent`，模型传输与工具执行仍回到宿主。Node SQLite 保存业务对象、证据、版本、队列与回执；地图的地理事实、显示几何、路线及观看状态各有职责。

技术栈：Electron、React、TypeScript、Node SQLite、Hermes Python、MapLibre GL JS；OpenLayers 提供平面兼容视图；OpenUI 1.0.1 渲染宿主验证的业务Scene与有限声明式交互程序，不承接第二套聊天或工具执行循环。模块与数据所有者见[架构](docs/ARCHITECTURE.md)。

第五批本地语义候选及其固定资源记录仍保留在[原批次状态](docs/CURRENT_STATUS.md#personal-memory-round5)。当前默认 ContextCompiler 不注入该候选服务；理解、理由比较和主动取证沿现有主模型及 Hermes 子调查完成，没有为本轮新增模型或代理循环。资源安装不作为本轮体验成果。

## 本地运行

当前工具链为 Node **24.18.0**、npm **11.16.0**，桌面目标 **Windows x64**。Hermes 固定为 0.21.2、提交 `d595e636c83aa0b9606d4e914e1140ae9c796897`，使用 Python 3.13 和冻结的上游 `uv.lock`。安装 Python 与 uv 后：

```sh
npm ci
npm run setup
npm run dev
```

普通启动以 DeepSeek 为生产默认。模型密钥从桌面连接界面私下输入并按系统机制保存；项目已授权的 Windows 凭据也可由 `npm run deepseek:check` / `npm run dev:deepseek` 使用。校园连接器位置、独立数据目录见 [.env.example](.env.example)。不要把凭据或运行数据写入仓库。

测试阶段仅使用已有 Codex 账号的 **GPT‑6 Luna Max 临时代测通道**，禁止为测试调用 DeepSeek：

```sh
npm run dev:luna:test
# 构建后，也可运行：
npm run start:luna:test
```

该通道只替换模型传输，仍使用同一 Hermes、权限、天气、校园适配和动作链；它不等于产品已有通用 ChatGPT 登录。Node 请求优先使用显式代理环境变量，Windows 未指定时沿用已开启的系统手动代理；此通道不执行 PAC。

只看公共地图不需要账号、密钥或 Hermes：

```sh
npm ci
npm run review
# http://127.0.0.1:5174
npm run build:review
npm run preview
# http://127.0.0.1:4173
```

公共预览只包含固定公共地图及本地选点、相机和路径交互，不含聊天、记忆、设备定位、账号或模型请求。[云端审查](docs/CLOUD_REVIEW.md)说明确定场景和历史部署版本；本地新增代码不代表线上自动更新。

## 设计与当前限制

帮助以用户的决定权和当下需要为中心：保留原话与条件，允许不知道、纠正和停止；先做有用准备，已有授权内少问，实际缺口才询问。界面用内容与直接操作解释结果，细节按需展开。地图保留暖灰／金色与空间观看能力，估计接入、静态来源和现场未知如实区分。[产品约定](docs/PRODUCT_CONTRACT.md)维护这些原则。
