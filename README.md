# 在场

在场是一位可以选择和塑造性格的持续陪伴者。你可以和她或他聊天、学习、一起创作、商量安排，也可以托付具体的事情。角色的亲近感贯穿整个过程：查资料、调用工具、等结果、遇到失败、回来接着聊的时候，都是同一个熟悉的伙伴。

她会在你允许的范围内找回相关的原话和你们一起经历过的事，按托付和相处约定主动留意变化、准备帮助，也会偶尔只是来打个招呼、带来一点有意思的东西。地图、日程、成绩、学习纸和可以拖动的小实验能直接出现在对话里，你指着它继续说，交流就沿着同一个对象接下去。

我们把自然表达、真实能力和长期连续性一起设计：说话可以亲近、俏皮、认真，事情必须有真凭实据——“回来啦，有点想你”是心意，“我刚帮你查过成绩”必须真的查过。

## 2026-10-21：这次改了什么

这一轮继续在本地完善人格、记忆、工具、主动陪伴与动态内容。用户完整目标和后续补充保留在[本轮原始要求](docs/source-materials/2026-10-21/README.md)。详细说明与分层证据见[当前状态](docs/CURRENT_STATUS.md#deep-refactor-20261021)；工作仍在进行，没有推送、部署或发布新版 EXE。

- **每个形象都有自己的性格。** 澪、遥、朔、凪有了按立绘原创的人格；新用户默认见到的澪，聊起来也是澪。丰川祥子、若叶睦的演绎改为依据官方人物介绍全文和两位声优的访谈（[来源记录](docs/research/CHARACTER_SOURCES_2026-10-21.md)），Gemini 写的台词原样保留。没保存过的默认角色会跟着你选的形象走，你保存过的设定永远不会被改动。
- **先让模型认识她，再一起理解事情。** 角色卡用第二人称写在最前面，Gemini 的人格和生动例句继续保留。共同原则、工具方法、用途判断和收尾反馈改用充分的同伴式说明；资料、许可、版本与实际结果仍由原机制照管。
- **工具可以按需要发现。** 常用工具直接提供，专门工具通过 `use_tool` 搜索、分页发现和读取真实签名；正在进行的活动保留直接入口。一次当前澪角色检查得到 34 个工具、54,907 字符，实际数量随当轮范围变化。
- **她边做边说，也认真听清限制。** 同一主助手的公开正文可以在工具运行中出现，后续解释和画面接着展开。每条可以送模型的原话都经过语义控制理解，普通情况可用简洁的空提案；没有某个关键词不再被当作不存在保存或来源限制的证据。
- **主动这件事接上了真实链条。** 明确约好的提醒按时间单独调度，可以覆盖安静时段；系统通知是否显示或发声还取决于系统与当前设置。通知可显示她的话，也可隐藏正文，点开回到原对话。关掉窗口后默认留在托盘，按当前设置和仍有效的托付继续；“主动来聊”允许她偶尔先开口，没回复就不会接着追。
- **OpenUI 表达式与直接互动继续扩展。** 曲线、滑块、拖点和有限动效沿同一共享库工作；按住／松开、有限合成声音、通用几何与跨重开局部状态已经接入。完整交互作品、逐段制作与地图动效仍在实际收口，不以小部件可用代替完整体验。
- **界面说人话。** 首页用你约定的称呼和她的一句话问候；“按需参考资料”“查看处理过程”“核对本轮资料范围”这类字样换成了“参考了什么”“刚才做了什么”“读你这句话”；失败时会说“这次没连上，你的文字还在。”

本轮已有实际返回 `gpt-6-luna` 的记忆提取／纠正／跨会话回忆、图片和 PDF 像素观察、公开资料续问、校园只读以及主动作品交付证据；每项范围分别记录。校园快照的跨重开续页与当前页比较、受托笔记变化回告，以及正常重开后再读原消息图片均已取得限定结果。完整钢琴机构与最终整合体验继续推进。托盘、开机启动与真实 Windows 通知还需各自的设备证据；邮箱与学校写入没有接入，新版便携 EXE 尚未发布。见[接续入口](docs/CONTINUE_FROM_HERE.md)。

## 现在能做什么

| 能力 | 现在的样子与边界 |
| --- | --- |
| 角色与关系 | 十个起点：澪、遥、朔、凪、丰川祥子、若叶睦、温暖学姐、元气搭档、冷静参谋和自定义。名字、自称、称呼、性格、说话方式和例句都能改，有版本、撤回和模板导入导出；外部角色卡只导入可编辑文字。形象和性格分开保存，换图不会偷偷改掉你写的人格。 |
| 对话 | 她先接住你这句话；需要时自己去查日程、校园、天气、地图、笔记和以前聊过的事，不用你报工具名。查的过程中可以先说一句，结果回来接着往下说。你中途补一句，以新的意思为准，已经办成的结果保留。 |
| 主动 | 托付过的事在允许的来源和期限内持续留意，有真正有用的变化时按约定渠道联系；也可以安静准备。“主动来聊”可设为不用／偶尔／常来。明确约好的提醒单独按时间调度；应用内联系不额外授予系统通知许可。 |
| 记忆与连续性 | 原话和带条件的理解分开保存；需要前情时她会主动深读当时的理由和后来的变化（`recall_experience` 让同一 Hermes 派出只读子调查）。纠正立即生效，局部遗忘会连同派生内容一起清掉，独立的内容保留。 |
| 对话内画面 | 地图、天气、空气、课表与成绩、日程、笔记原页、商量纸、陪学纸及通用交互作品可以与正文穿插。作品支持有限图形、表达式、局部输入、按压、声音和动效；局部值可随同一消息恢复，按住、播放和发声状态重开时复位。点选只是指着说，不代表接受或执行。 |
| 资料与学习 | TXT/MD/PDF 分页阅读、原文定位、真实图片与 PDF 页像素观察、局部放大和数学排版；公开网页图片既能展示，也能按需要让主助手实际看见。独立 OCR 管线尚未接入。 |
| 记事本 | 独立原文、搜索、编辑、版本、撤销与回收站；记下想法不会自动排进日程。 |
| 安排 | 事件、待办、截止、提醒、时间块、重复与单次例外；规划会算上准备、收尾、转场、休息和留白，按真实时区的自然日核算；明确委托的本地修改直接办好，其他的先给可审阅方案。可导出有限范围的 ICS。 |
| 校园与公开资料 | 已接校园查询适配（需在本机安装并授权连接器）、公共地图、Open-Meteo 天气与空气、公共搜索与网页读取。学校写操作（预约、选课、支付）没有接入。 |
| 体育有效次数 | 当前连接器没有学校体育有效打卡次数及审核记录的读取入口；二三四课堂实践记点不代替体育认证。可以结合本人提供的实际记录和对应规则核对，未取得记录时次数保持未知。 |
| 失败与恢复 | 区分建议、已保存、等待确认、结果未知和真实回执；超时先核查原动作，不重复提交；失败时保住已经拿到的部分，用一句人话说清还缺什么。 |

## 系统组成

Electron main 负责本机数据库、凭据、权限、工具和副作用；React renderer 通过有限 Bridge/IPC 显示内容。一个固定版本的 Hermes Python `AIAgent` 是唯一的主循环，模型请求和工具执行都回到宿主；Node SQLite 保存业务对象、原话、版本、队列与回执。运行时的提示由 `src/main/runtime/prompt-composition.ts` 统一组装（角色卡 → 原则 → 相处约定 → 边做边说 → 本轮），模型看到的工具面由 `src/main/runtime/tool-surface.ts` 决定。机制细节见[架构](docs/ARCHITECTURE.md)，文件位置见[导航](PROJECT_NAVIGATION.md)。

技术栈：Electron、React、TypeScript、Node SQLite、Hermes Python、MapLibre GL JS（OpenLayers 提供平面兼容视图）、OpenUI 1.0.1。

想看模型实际收到了什么：

```sh
node scripts/inspect-prompt.mjs mio            # 澪；也可以换成 sakiko、mutsumi 等
node scripts/inspect-prompt.mjs sakiko --full "今天好累"
```

它在内存里用合成文字组装一次真实的系统提示、工具面和上下文包，按来源列出各段大小，不调用任何模型。

## 本地运行

当前工具链为 Node **24.18.0**、npm **11.16.0**，桌面目标 **Windows x64**。Hermes 固定为 0.21.2、提交 `d595e636c83aa0b9606d4e914e1140ae9c796897`，使用 Python 3.13 和冻结的上游 `uv.lock`。安装 Python 与 uv 后：

```sh
npm ci
npm run setup
npm run dev
```

生产默认模型是 DeepSeek，密钥在桌面连接界面私下输入并由系统机制保存；项目已授权的 Windows 凭据也可由 `npm run deepseek:check` / `npm run dev:deepseek` 使用。校园连接器位置与独立数据目录见 [.env.example](.env.example)。不要把凭据或运行数据写入仓库。

已有的 GPT‑6 Luna 临时代测通道（`npm run dev:luna:test`、构建后 `npm run start:luna:test`）只替换模型传输，其余链路相同。它不是继续开发的全局前置门槛；本轮测试禁止调用 DeepSeek。实际型号看响应记录，Luna 实际用量继续计量，完整结果不会仅因本地 token 声明被事后丢弃。

只看公共地图不需要账号、密钥或 Hermes：

```sh
npm ci
npm run review          # http://127.0.0.1:5174
npm run build:review
npm run preview         # http://127.0.0.1:4173
```

公共预览只包含固定公共地图和本地的选点、相机、路径交互，不含聊天、记忆、定位、账号或模型请求。[云端审查](docs/CLOUD_REVIEW.md)说明历史部署版本；本地新代码不会自动更新线上站点。

## 当前限制

- 关掉窗口后默认留在托盘；电脑睡眠、关机或彻底退出时会停下。恢复运行会重新检查到期事项，提醒按当前渠道处理，托付继续核对期限与设置。手机、跨设备同步和离开电脑后的云端常驻都没有做。
- 系统通知只能确认“交给了操作系统”，不能证明你看到了。
- 邮箱、钉钉等外发，以及学校预约、选课、付款都没有接入；外发只会生成草稿。
- 整个本地数据库尚未加密。

项目代码未授予开源许可。地图、字体、引擎、原生运行时与其他依赖的来源和许可见[资产来源](docs/ASSET_PROVENANCE.md)、[地图数据说明](assets/map-v2/SOURCE.md)和[第三方声明](THIRD_PARTY_NOTICES.md)。私人研究资料、个人数据库、账号、私有地点、日志与未经授权的材料不进入远程仓库或应用包。较早各批次的说明保留在[当前状态](docs/CURRENT_STATUS.md)与[Harness 演进](docs/HARNESS_EVOLUTION.md)。
