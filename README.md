# 在场

在场是面向大学生日常生活的持续陪伴者。聊天、硬核学习、共同创作、日程商量、笔记与校园出行围绕同一段交流展开：有需要时把资料铺开、让地图从回答旁展开；回来时接住原来的问题和草稿。角色可以亲近、有趣，也应在认真做事时让出空间。

温暖来自具体帮助和连续性。角色可以说想念，也可以陪你安静坐一会儿；“刚才查过”“已经保存”必须有真实来源或业务回执，图稿和示例数据不能代替真实能力。

| 模块 | 当前实现 |

## 系统与本地运行

Electron main 管理 SQLite、凭据、权限和动作；React renderer 通过有限 Bridge/IPC 工作。链路为 `harness.ts → runtime/hermes.ts → sidecar.py →` 锁定 Python `AIAgent`。技术栈还包括 MapLibre、OpenLayers及固定OpenUI 1.0.1。

Node **24.18.0**、npm **11.16.0**；桌面目标 Windows x64。Hermes **0.21.2**、Python **3.13**，具体依赖以锁文件为准。

```sh
git lfs pull
npm ci
npm run setup
npm run dev
```

生产模型默认 DeepSeek；凭据在桌面连接界面私下配置，连接器路径与独立数据目录见[.env.example](.env.example)。当前授权模型测试使用 `npm run dev:luna:test`，构建后可用 `npm run start:luna:test`，不测试调用 DeepSeek；实际返回型号须看响应记录。Luna是显式代测通道，不是产品ChatGPT账号登录或全局开发门槛。

公共地图不需要模型、账号或Hermes：

```sh
npm run review
npm run build:review
npm run preview
```

review只包含选定公共地图；本地新代码不会自动发布到历史站点。完整桌面并非普通review网页。
