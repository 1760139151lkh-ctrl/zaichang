## 当前使用与分发边界（2026-10-18）

本文件保留2026-10-03、10-04的研究观察；其中“本轮”“当前”和待办描述属于所注明日期的记录，不自动证明后续数据、现场通行或发布状态。现行实现与文件入口见仓库的 `PROJECT_NAVIGATION.md`，来源和权利总表见 `docs/ASSET_PROVENANCE.md`，当前限制见 `docs/CURRENT_STATUS.md`。本文件不是新一次外部来源核验或部署回执。

桌面与公开 review 共用 `src/main/mapService.ts`、`src/shared/map-routing.ts` 和 `src/renderer/map/`。公开文件集合由 `vite.review.config.ts` 与 `scripts/check-review.mjs` 限定为九份运行时JSON/GeoJSON及去个人字段的OSM源压缩包；浏览器存储只预载九份运行时数据，拒读其他文件。`shared-bridge.mjs` 是同源生成的本地技能适配入口，不是公开网页另一个地图实现。个人地图配置由桌面启动入口显式提供，review没有该目录，也不读取个人角色、地点绑定或定位。

普通 `npm run build` 使用已经保存并校验的地图快照，只重新编译共享桥和应用；不重新抓图或生成全套地理资料。`npm run map:import` 才运行受保护的完整再生成流程，要求 `ZAICHANG_MAP_REFERENCE_DIR` 指向另行授权的本地参考目录。下文提及的 `official-coverage-reference.json`、`official-locator-source.tsv` 是本地参考输入，不是公开发行文件；公开名称、来源链接和有限对应元数据与原始导出分开处理。原始图像、截图、令牌和个人资料不进入Git、桌面地图资源或公开预览。

后续显示修订仍保留原始地面与路线事实：西田径场的实际道数未知，当前示意分道通过 `displayLaneCount/displayLaneBasis` 与 `laneCount` 分开；水系可沿已有敞开源中线形成有宽度依据或明确制图估值的显示带，显式 `tunnel/covered` 决定覆盖表达，负 `layer` 本身不证明地下；公寓补充屋顶轮廓、地铁入口、档案馆及住宅高度代理各保留自身来源与未知范围。下列早期记录中的“西场不画道数”“不补显示水道”或 `layer<0` 简写不能覆盖这些现行规则，也不能据新显示反推实测尺寸、入口或可靠通行。

以下为保留的历史来源记录；其中公开资料的可访问性不等于再分发许可。当前地图的事实、覆盖和衍生使用权利门槛仍按来源总表逐项审查。

官方图像版权归浙江大学。当前是用户已授权的本地个人研究与使用；没有取得面向公众重新分发官方图像的许可。Electron不打包官方栅格、官网脚本或服务令牌。显示观察随本机地图记录依据与署名；对外分发时另行确认相应素材权利，不能把WFS的`AccessConstraints: NONE`当作任意再分发许可。

## 坐标与身份

公共地理为WGS84 `[longitude, latitude]`，显示经Web Mercator投影。原定位索引使用UTM51N，局部原点为 `[217000,3355200]`米。官方鸟瞰按其公开转换公式保留30°／45°视角；屋顶、侧面和阴影不当作地面，未重新拟合一套全图变换。没有混入GCJ-02／BD-09，也未从屏幕像素直接计算路程。

新版WFS编号和定位技能的旧数字ID分开命名空间，以名称和地面位置共同核对；未核实的对象保留参考点。个人角色、备注、改名和移动参考点只读技能的活动配置，在场和技能共享同一文件字节版本。望月公寓、桂花苑及“家”不自动等同；紫云六舍不补猜位置。

## 派生与可重建性

唯一公共生成链为 `scripts/import-map.mjs` 调用源归一化、`build-map-v3.py`、`build-map-bridge.mjs`。不覆盖原始OSM或个人配置。`manifest.json`最后写入，记录各事实组件哈希；目录名map-v2和wire版本保留兼容，implementation明确为campus-map/v3。

- `geography.geojson`保留路由用的地面事实；`display-geography.geojson`单独承载显示细分、体育观察及图层分工。内院、孔洞、多部件保留。
- 文字锚点是渲染时从显示楼体内部及屋面求出的显示位置，和`places.coordinate`、门点及路网参考点分开。简称只取已有有效别名；个人命名不自动缩写。标注高度对应已显示的源高度／概化模型，不是新测绘事实；地图切回平面时按地面位置显示。
- `places.json`和`network.json`保存稳定身份、已记录入口、步行节点及边。只有源共享节点或对同一已记录边的有依据细分才连通，画面交叉不自动连路。
- 有真实记录的入口先比较所有合格入口；缺门时在80米内最多6个避障接入候选间比较，路段和估计接入分别计米。条件门、权限／时段及未核实室内连接默认不当可靠捷径。顶棚与楼下通道只描述物理覆盖，不自动等于步行禁入；楼栋可选不等于门已确认。
- `sports-details.geojson`是依运动类型、源场地和官方可见结构生成的制图示意；篮球／网球／足球场线不表示测得的尺寸。东场的源参考环线不是标准跑道测量线，学校介绍明确东西场名义400米，和派生环线长度分开记录。西场不补造测量线或道数。预览不产生跑步完成记录。
- 有源高度时表达来源体量；仅有层数时用每层3米作明确示意。缺乏可靠形态资料的建筑保持轮廓；有建成照片支持但精确高度未知的模型单独注明影像比例概化，不伪造室内模型。月牙楼与体育馆依据原设计／实际查看的图像概化曲面结构；气膜馆约18米来自学校介绍。具体曲率、檐高、塔筒与分缝为有依据的简化，不冒充取得了测绘模型。

`shared-facts.json`记录当前对应、显示依据、场馆能力和限制，`shared-bridge.mjs`让App与定位技能调用同一适配器。当前求路独立核对使用免费SciPy HiGHS、Python Dijkstra及边势，不再要求商业Gurobi许可。最短性仅限同版图与候选集合；门禁、施工、现实缺边仍需现场确认。
