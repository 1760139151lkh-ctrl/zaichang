The export card identifies the original BAAI model. The export repository at
this revision has no separate LICENSE file or license field. This distribution
retains the original model's MIT license basis and the export attribution; it
does not claim that Xenova published an additional independent license.

The application distributes only the fixed q8 ONNX graph and its three JSON
configuration/tokenizer files; it does not train or modify those files.
The complete pinned file list, sizes and SHA-256 values are in lock.json in
the embedding runtime directory. Inference remains local; no model Hub client
or automatic runtime download is used.
