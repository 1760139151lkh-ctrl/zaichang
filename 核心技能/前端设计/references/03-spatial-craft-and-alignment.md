# 03 · 空间秩序、光学对齐与色彩主题层：统一网格、暖灰金四主题与「修错不毁好」

> **核心位置**：第三优先级（秩序与工艺层）。吸收 `product-design-director/references/craft.md` 与 `FRONTEND_DESIGN.md`，解决“单张图好看但塞进页面就错位”、“买家秀与卖家秀割裂”以及“乱改把已对齐地方改坏”的核心痛点。

## 一、三栏空间退让法则（Adaptive Spatial Yielding）

「在场」不是左右死板平分的后台管理系统，而是**同一间窗边居室内的镜头与重心流转**：

```
┌──────────────────────────────────────────────────────────────────────────┐
│ [左上：品牌与场景胶囊 (固定锚点)]              [右上：主题/角色/状态轻胶囊] │
├─────────────────────────────────────────────┬────────────────────────────┤
│                                             │                            │
│   主工作台区 (Workbench Stage: 68% - 75%)   │  窗边陪伴舞台 (25% - 32%)  │
│   - S1 首页时收起为透明，显露完整居室背景    │  - 角色始终坐在真实家具上  │
│   - S2 学习：题卡 + 公式 + 钢琴/波形互动卡  │  - 随左侧任务展开，镜头与  │
│   - S3 资料：真实 PDF 页面 + 选段浮层       │    站位平滑右移退让        │
│   - S4 日程：时间轴 + 试放块 + 冲突留白     │  - 角色下方为轻量对话流与  │
│   - S5/S6 笔记与全屏校园地图                │    可折叠状态回执          │
│                                             │                            │
├─────────────────────────────────────────────┴────────────────────────────┤
│ [底部收藏书签横托盘 (按需平滑浮现)]                                      │
│ [底部胶片质感统一输入栏 (跨页面锁死底部基线与左右边距，绝不跳动)]        │
└──────────────────────────────────────────────────────────────────────────┘
```

### 空间退让的三条硬规则
1. **同一房间连续运镜**：从 `S1 首页` 切入 `S2 学习` 或 `S3 资料` 时，背景居室不销毁重建，而是通过平滑的镜头平移/景深微调（或同机位右侧伴读姿态切换），让左侧自然浮现磨砂玻璃工作台。
2. **角色绝不遮挡核心正文，工作台绝不压迫角色头部**：
   - 右侧伴读区必须保证角色头部、肩部与手部动作位于通透安全区内（Safe Zone），任何气泡或按钮不得横切角色面部。
3. **返回首页零闪烁**：收起工作台返回 `S1 首页` 时，输入框、顶部导航栏与地图/PDF 缓存状态保持原位，不重新挂载造成画面闪白。

## 二、跨页面统一槽位标尺（Unified Slot Ruler）

为了彻底消灭各页面之间“按钮一会儿偏左、一会儿偏下、内边距各行其是”的错位现象，全站必须共用以下 CSS 变量标尺（写入 `tokens.css` 并全局强制继承）：

| 槽位名称 | CSS Token 标尺 | 刚性对齐要求 |
| :--- | :--- | :--- |
| **外框安全边距** | `--stage-pad-x: 24px; --stage-pad-y: 20px;` | 全站 9 大场景的顶栏、底栏、侧栏外边缘必须严丝合缝对齐此参考线 |
| **顶部导航栏高度** | `--topbar-height: 48px;` | 左上导航胶囊与右上工具胶囊共享同一水平中心线（`align-items: center`） |
| **顶部胶囊规格** | `--pill-height: 36px; --pill-px: 14px; --pill-radius: 999px;` | 图标 `16px`，文字 `13px/500`，图标与文字间距固定 `6px` |
| **工作台卡片圆角** | `--card-radius-lg: 22px; --card-radius-md: 16px; --card-radius-sm: 12px;` | 遵循同心圆角公式：$R_{outer} = R_{inner} + Padding$，严禁内外圆角打架 |
| **底部输入栏基线** | `--composer-bottom: 20px; --composer-height: 56px; --composer-max-w: 760px;` | 无论在首页、学习还是笔记页，底部输入栏的垂直位置与高度分毫不差 |
| **分屏可拖拽间距** | `--split-gap: 16px;` | 左侧主工作台与右侧陪伴区之间的拖拽手柄热区宽 `16px`，视觉指示线宽 `3px` |

## 三、四套完整场景主题与色彩铁律（Warm Cream-Grey-Gold & 4 Themes）

所有主题均建立在**温暖奶油色、柔雾暖灰与香槟柔金**的高级材质基底上，支持浅色（Light）与深色（Dark）平滑切换：

| 主题代号 | 主题名称 | 表面基底色 (`--surface-glass`) | 强调色 (`--accent-primary`) | 文字主色 (`--text-primary`) | 适用光影氛围 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| `apricot` | **暖杏（默认）** | `rgba(255, 250, 243, 0.78)` | `#D4845A`（暖焦糖杏金） | `#2C241E`（深焙暖棕黑） | 午后阳光斜照木桌与床沿 |
| `mist` | **晨雾蓝** | `rgba(246, 249, 253, 0.80)` | `#5B7FA6`（清透雾霾蓝） | `#1E2631`（深岩蓝灰） | 清晨微光、安静早读与思考 |
| `violet` | **暮色紫** | `rgba(250, 246, 252, 0.78)` | `#8E6B9E`（晚霞柔紫金） | `#28202E`（深暮紫灰） | 傍晚霞光、课后放松与回顾 |
| `rain` | **夜雨暖金** | `rgba(28, 32, 42, 0.76)` | `#E5A952`（琥珀台灯金） | `#F5EFE6`（暖羊皮纸白） | 窗外夜雨与绿植暗影、室内暖灯 |

### 色彩与过渡三大红线
1. **绝对禁止绿色 UI**：任何主题下的背景底色、卡片边框、主次按钮、进度条、选中态均严禁使用绿色（仅允许窗外自然植物景观与若叶睦原作发色/领结保留固有色）。
2. **绝对禁止昼夜分割线与左右箭头**：严禁在画面上做“左半边白天、右半边黑夜、中间一条竖线加左右箭头”的割裂式对比滑块！主题切换必须是整间屋子光影、色温与角色受光的**全画幅整体柔和融变（Cross-fade 400ms cubic-bezier）**。
3. **文字对比度与可读性保护**：半透明玻璃卡片背后必须配 `backdrop-filter: blur(20px) saturate(135%)` 及微妙的渐变衬底，确保文字在任何背景立绘上都清晰易读，绝不发花。

## 四、「修错不毁好」光学对齐手术法则（Surgical Alignment Protocol）

借鉴 `product-design-director` 的 Craft 原则，在调整任何 UI 布局时严格执行以下四步法：

1. **先锁定保护区（Freeze What Already Works）**：
   - 在动手改 CSS 前，先列出当前页面已经对齐良好的组件（如已对齐的日程卡片内部排版或顶部导航胶囊），禁止对其使用全局通配符覆盖。
2. **用眼睛做光学审校，而非只看像素数值（Optical Over Mathematical）**：
   - **视觉重心修正**：三角形播放图标在圆形按钮内需向右微移 `1px–1.5px` 才显得居中；中英文混排胶囊的上下内边距需根据字怀高度做微调，避免文字看起来往下掉。
   - **边缘齐整度（Edge Alignment）**：同一列中的标题、正文首字、底部标签胶囊左边缘必须落在同一条垂直视觉引导线上，不要出现 `2px–4px` 的无意义缩进参差。
3. **字号与层级收敛（Typographic Discipline）**：
   - 全站单屏内最多允许 **4 级字号**：
     - 页面/卡片主标题：`18px–20px` (`font-weight: 600`, `letter-spacing: -0.01em`)
     - 正文与对话内容：`14.5px–15px` (`line-height: 1.65`, 舒适阅读宽 `55–68ch`)
     - 辅助信息与按钮文案：`13px` (`font-weight: 500`)
     - 来源胶囊与时间戳微标：`11.5px–12px` (`tabular-nums` 等宽数字，防止时间跳动)
4. **响应式与窗口缩放防崩**：
   - 在 `1280×800`、`1440×900`、`1920×1080` 三种典型桌面视口下核验，确保卡片不重叠、文字不截断成无意义省略号、角色脚部与床沿不被意外裁切。
