# 后期处理与成片检查

按用户授权处理本地成片，保留原文件。以下说明方法的适用条件，不预设当前机器已经安装某个编辑器或滤镜。先用已有工具；不为研究技能安装开源模型，不调用新的付费生成服务。

## 接缝方法的选择

| 方法 | 何时有帮助 | 不能解决什么 |
| --- | --- | --- |
| 找周期并修剪 | 同一动作重复，能找到相近状态和运动趋势 | 不同人物姿态、错误物体、整体光照突变。 |
| 正放接倒放 | 可自然反向的小幅摆动、呼吸式形变，端点运动较慢 | 连续转向、物理不可逆事件、行走／对白倒放。快运动端点会急刹。 |
| 短交叉淡化 | 静稳背景或两个状态差异小；必要时仅淡化局部 | 运动轨迹不接、双像、透明拖影；更长淡化可能更明显。 |
| 配准／稳定后裁切 | 小幅全局平移、旋转或缩放漂移 | 前后景视差、局部形变、遮挡、照明变化；可能损失画面边缘。 |
| 局部遮罩合成 | 仅背景／局部细节变化，主体可保留稳定层 | 动态边缘、发丝／玻璃和移动遮挡仍需精修。 |
| 重复帧／定格 | 用户接受静止停留或封面 | 无法补出真实运动，会产生顿挫。 |
| 帧混合 | 小幅变速时愿意接受运动拖影 | 无法修补内容跳变，容易重影。 |
| 光流补帧 | 运动连续、边缘清晰的变速或帧率转换 | 遮挡、快运动、烟水、形变易撕裂；不能凭空连接无关端点。 |

这些边界依据 [FFmpeg 滤镜文档](https://ffmpeg.org/ffmpeg-filters.html)、[MoviePy 上游代码](https://github.com/Zulko/moviepy/blob/master/moviepy/video/fx/TimeMirror.py)及编辑工作原理。`reverse` 需要缓冲输入，处理前先裁出所需短段；MoviePy 的 TimeMirror 还会作用于已有音轨与 mask，不要无意倒放对白。`xfade` 的两路输入须为恒定帧率，并匹配尺寸、像素格式、帧率与时间基，按真实时长设置重叠区。实际命令应根据媒体规格和已安装版本生成，不照抄固定秒数／帧数。

正放＋倒放拼接时，检查两个转折处是否重复同一端点；需要时去掉反向段的共享端点，而非复制一帧制造停顿。循环淡化可让片尾与片头一小段重叠，成片周期会缩短；对齐后的视频与音频时长，不能把两个完整片段淡接一次就称为圆形循环。

全局配准项目 [comfyui-seamless-loop](https://github.com/amagicai/comfyui-seamless-loop)使用特征匹配和 2D 变换校正取景，值得借鉴其能力边界；不把它当作 Gemini 的内置功能或默认依赖。

## 声音另行处理

视觉和声音可采用不同方案。装饰背景按需求静音；环境声可独立做周期，避免把声音一起倒放。语句不要从中间截断；音乐要对齐拍点／乐句，短淡化不能修正错误节拍。接缝听到 click 时检查波形突变，必要时短音频淡化；相位不合仍可能有音量凹陷。重新编码后还需听实际文件，留意编码延迟或填充。

## 按实际用途验收

先读真实像素、时长、帧率、编码、文件大小、有无音轨；这些只证明文件规格。需要确认文件有效时用现有解码工具完整读取，再正常速度完整播放。

循环片用实际播放器连续回接观看多轮（例如三轮），专门观察跨接前后几帧及运动趋势，再看整体是否因每圈停顿产生节奏感。慢放／逐帧用于定位，最后回到正常速度判断；contact sheet 只能辅助检查外观，不能证明速度、连续播放或音画同步。

| 观察维度 | 典型缺陷 |
| --- | --- |
| 主体与几何 | 换脸、部件增减、杯柄换边、Logo／文字变形、背面凭空变化。 |
| 动作与接触 | 脚滑、手指穿透、物体悬空、轨迹断裂、倒放感、突然冻结。 |
| 时间稳定性 | 纹理沸腾、背景漂移、高光跳闪、曝光／色温变化。 |
| 接缝 | 硬跳、瞬间反向、速度突变、重复端点停顿、交叉淡化重影。 |
| 构图与用途 | 手机裁掉主体、标题区太忙、封面与播放起点突跳、黑边／拉伸。 |
| 音频 | 拼接 click、重复音节、断句、音量突变、节拍错位、口型不同步。 |

借鉴 [VBench](https://github.com/Vchitect/VBench) 的多维评价思路，分别看一致性、闪烁、运动和平稳性；不安装基准或编造总分。完全静止的视频可能很稳定，却没有完成动作要求；首尾很像也可能中间变形。没有通用像素差阈值能替代观看。

发现问题就定位来源并在授权范围内修正、重新导出、重看相关片段。交付时简述实际处理与检查；若只研究或写提示词，明确尚无成片，不把“计划检查”写成“已经通过”。
