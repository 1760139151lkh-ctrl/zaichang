# 提示词与控制方法

这是给 Codex 组织创作描述的工具箱，不是要求用户填写的表单，也不是专用参数语法。下面的例子均为本技能原创。对当前 Omni 使用当前指南；旧 Veo 的创作技巧只作为可迁移思路，不作为网页硬参数依据。

## 组织描述

按“主体与外观 → 环境 → 动作及变化 → 镜头／构图 → 光线／风格 → 声音 → 必须保留或排除的内容”组织。明确结果比堆“超清、杰作、电影级”更有用。镜头、主体、动作、环境及风格这套结构来自 Google 的创作指导；中文意思应首先准确，镜头术语可辅以英语。[Google 官方创作指南](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-veo-3-1/)

| 希望控制什么 | 描述方式与用途 |
| --- | --- |
| 主体一致 | 说明同一角色的服饰、轮廓、颜色、相对位置，并明确参考图中谁是主体。 |
| 主体运动 | 写可观察的动作、方向、速度与终态，如“从画面左侧缓慢游向中央，最终停在红色浮标旁”。 |
| 镜头运动 | 区分主体运动与相机运动。“镜头固定，主体走近”与“相机推近静止主体”是不同需求。 |
| 推进与变焦 | 推进改变机位与透视；变焦改变取景大小。需要哪种就明确说明，避免同时要求互相矛盾的运动。 |
| 构图 | 远景交代环境，中景表达动作，特写强调细节；明确主次与前后景。 |
| 焦点 | 说明对焦对象、背景虚化或由前景转向背景，不把“微距”和广阔全景混写。 |
| 风格与光线 | 描述材质、时代、色调、光源方向和气氛；使用少量相容的风格。 |
| 节奏 | 给自然语言时序或时间段；细化关键变化，避免把十秒塞成复杂长片。 |
| 一镜到底 | Omni 可能主动切镜，明确要求连续镜头，例如 `single continuous shot`、`no scene cuts`。 |
| 多镜头 | 分段交代每镜主体、视角及衔接；不要同一处又要求完全无剪切。 |
| 对白 | 标记说话人、说话语言、确切台词和语气；台词放引号，短句更易在短片中容纳。 |
| 音效／环境音／音乐 | 分别描述事件音、持续背景声和配乐情绪；要无配乐或无人声就明确说明。 |
| 文字 | 引号写出确切内容、位置与出现时段；必须在成片检查字形和拼写，提示词不能保证逐字正确。 |

镜头、构图及音效的描述方向参考 [Google 创作指南](https://cloud.google.com/blog/products/ai-machine-learning/ultimate-prompting-guide-for-veo-3-1/)。Omni 的连续镜头、时序、排除项和局部修改写法参考 [Omni 提示词指南](https://ai.google.dev/gemini-api/docs/omni)，其自然语言方法可用于网页；其中的 API 参数不迁移到网页。

## Omni 修改、续接与约束

局部修改通常用短而明确的指令，并要求其他部分保持一致；可以补 `Keep everything else the same`。排除要求直接放在正常描述中，例如“无旁白、无额外人物”，不要虚构网页存在 `negative_prompt` 字段。时序可以用“第三秒”或 `[0–3s]` 等写法，但这是引导，不是逐帧强制控制。[Omni 官方指南](https://ai.google.dev/gemini-api/docs/omni)

实践建议（非硬性模型限制）：

- 新片先建立主要视觉和动作，再针对观察到的偏差修改；每轮只集中改变少数因素，避免无法判断哪个改动有效。
- 多张参考图明确分工，例如“图 1 的角色、图 2 的产品外观、图 3 的空间布局”。参考用途不能保证全部复制或像素一致。
- 不把参考图一概当作首帧。需要严格首尾帧时先查真实控件；只有上传图片及提示词时属于软引导。
- 续接从当前结尾发生的事写起，重申需要保持的角色与声音；先核对当次提供的续接能力。
- 中文描述可保留；如果结果偏离，可澄清歧义或补英文镜头术语。不要声称网页只接受英语。
- 用户指定的画幅、时长或像素仍要通过实际控件／输出文件核对。描述中的数字不自动成为精确媒体规格。

## 多素材、故事板与迁移方法

需要分离形象、构图和动作来源时，明确“图 1 只提供产品外观，图 2 只提供空间布局；不要继承图中的人物或文字”。使用实际附件称呼与顺序，不把 Seedance 的 `@图片1`、音频括号等专属写法当成 Gemini 解析字段，也不要为了达到附件上限塞满素材。

参考生成是借鉴输入；编辑是针对已有片段提出修改。想保留时间轴、动作和声音时明确走当前提供的编辑入口，不把重新参考生成当作逐帧保真的替换。两者都要核对未要求变化的区域。草图、白模或故事板可表达空间和镜头意图，但在网页只作为被模型理解的素材；没有真实姿态／关键帧控件，就不承诺精确坐标或帧绑定。

多角色对白分别写角色、语言、台词和情绪，字幕另写；换语言后要听原语言残留并看口型。将抽象情绪改成可观察动作，例如“嘴角轻扬、视线放松”，减少被字面画成发光眼睛或夸张变形的歧义。输入素材已有字幕、背景人声或音乐时，检查是否被无意继承。

Seedance 的 Draft 升级、seed、帧数规则、输出容器建议和 API 素材 role 均不直接迁移到网页；仅复用上述导演方法。网页是否有预览、清晰度、首尾帧或续接控制仍按当前界面与官方说明核对。

## 按用途继续设计

普通短片可直接使用下面的基础模板。自动循环先选[周期或 A→B→A](seamless-loops.md)，主页素材先确定[标题安全区、封面与裁切](product-hero-and-posters.md)，人物／产品复杂动作参考[接触和镜头关系](continuity-and-direction.md)。更多可改写方案见[原创场景配方](creative-recipes.md)。不要把所有参考中的约束一次塞入同一提示。

## 原创模板

按本次用户目标改写，省略不需要的字段；不要原样把所有例子批量提交。

### 文生视频：可观察的主体动作

生成横屏视频。清晨的河边，一只戴蓝围巾的小水獭从木码头左侧走到中央，把一枚鹅卵石放在木箱上，再抬头望向镜头。镜头固定在与它视线齐平的中景，连续拍摄，不切镜。薄雾、柔和侧光，真实自然的毛发。只听到木板脚步声和远处流水声，无对白、无音乐、无额外动物。

### 参考图：产品外观保持

以图 1 中的杯子作为唯一产品主体，保持杯型、图案和配色。杯子静置在浅色石台上，相机从左前方向右缓慢绕行，画面中始终能看到杯身标志。暖色窗光，背景简洁。杯子和桌面都不旋转，没有手进入画面，无新增文字。声音只有轻微室内环境音。

### 竖屏：动作节奏与字幕

生成竖屏短片，采用当前网页的 9:16 画幅。画面是一张深色书桌上的纸质地图：开头镜头俯拍；中段一条金色路径逐渐亮起；结尾镜头缓慢拉远，地图旁的指南针进入画面。字幕仅在结尾下方显示“出发”。保留足够字幕边距。轻柔的纸张声，结尾一个清脆铃声，无旁白。生成后需要检查文字与实际画幅。

### 对白：区分人声、环境与音乐

海边傍晚，两位朋友站在安静的栈桥上。中景、单一连续镜头。穿灰外套的人看向远处，用普通话轻声说：“我们明天再来。”另一人微笑点头，不说话。环境音是小浪拍击木桩和微风，无背景音乐。面部动作自然，不增加字幕。

### 局部编辑

将杯子后面的背景改为阴天的窗边。保持杯子外观、相机运动和原有声音不变，其他部分保持一致。

### 续接

从上一段的结尾继续：小水獭转身走向码头尽头，停下来看水面。保持蓝围巾、清晨雾气和原有中景视角，镜头不切换，流水声连续，无新增角色。

## 观察结果再修正

| 实际偏差 | 下一轮的针对性修改 |
| --- | --- |
| 相机和物体同时乱动 | 分开说明谁固定、谁运动，移除矛盾运动描述。 |
| 主体中途换脸／变色 | 重申参考主体和关键外观，减少无关变化；重看参考图是否冲突。 |
| 一镜到底被切镜 | 重申单一连续镜头，去掉会暗示蒙太奇的分镜语言。 |
| 音乐盖过对白 | 要求突出人声，降低或去掉配乐，必要时缩短台词后重听。 |
| 字幕不准确 | 简化并逐字指定，核对成片；需要确定性排版时在后期制作中实现。 |
| 像素仍不达标 | 检查实际下载规格；寻找真实清晰度选项，不能只重复“4K”。 |

这些是由创作目标推导的诊断建议，不是已在用户账号上逐项实测的保证。
