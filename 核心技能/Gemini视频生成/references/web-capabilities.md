# 网页能力与技术边界

核实日期：2026-10-24。数字属于对应产品和版本，使用时复核。优先级：用户账号的实际控件及错误提示 → 当前 Gemini Apps 帮助 → 该产品公告；API、Flow 资料只能证明其各自能力。

## 当前网页路线

个人账号需要 Google AI 套餐，工作／学校账号需要符合条件的 Workspace 许可；视频功能限成年人。Gemini Apps 已采用 Omni，支持文字创作、参考图片／视频、连续对话修改、画幅和模板。视频编辑存在地域限制，不能根据电脑时区判断账号资格。[Google 网页视频帮助](https://support.google.com/gemini/answer/16126339?hl=en)

| 项目 | 网页端结论与操作 |
| --- | --- |
| 文生视频 | “制作视频”中输入创作描述；不用准备 API Key。 |
| 图片参考 | 官方视频帮助写明最多 5 张图片，可配 1 段视频；给每张素材明确用途，实际上传控件为准。 |
| 视频编辑 | 在同一对话说明替换主体、改背景、改镜头等；上传编辑能力受地区与账号影响。 |
| 多轮修改 | 保留当前对话，一次提出清晰修改目标；不承诺其他细节绝对不变。 |
| 模板 | 可用风格模板引导初稿；不代表出现新的模型、分辨率或编码。 |
| 横竖屏 | 本账号现场菜单已确认 16:9、9:16。官方说明纯文本默认横屏，参考素材可影响画幅；提交前复查控件。 |
| 标准片段 | 当前 Gemini 产品页宣传 10 秒视频。网页是否支持自选其他时长须看当次界面，不能沿用旧 Veo 固定 8 秒结论。 |
| 续接 | 网页产品页支持延长场景。Omni 1.1 公告描述模型每次续接 10 秒、累计至 40 秒，并确认 Gemini app 开放续接；这不是本账号网页已实测的片长上限。 |
| 声音 | 支持原生音频，可在创作描述中指定对白、环境声、音效和音乐。 |
| 个人 Avatar | 官方支持使用自有头像分身作为创作素材；属于可选功能，当前账号的具体入口未核对。本技能不默认新建或录制真人分身。 |
| 导出 | 结果卡片下载，或分享菜单→下载视频。新建和修改不是对外发布授权。 |

图片数量、画幅和网页操作见[网页视频帮助](https://support.google.com/gemini/answer/16126339?hl=en)；10 秒、原生声音及 Omni 替代 Veo 见[Gemini 视频产品页](https://gemini.google/overview/video-generation/)；续接与产品可用范围见[Omni 1.1 官方公告](https://blog.google/innovation-and-ai/technology/developers-tools/build-with-gemini-omni-1-1-flash/)。

## 分辨率、时长和大小要分别处理

截至本次检查，本账号视频创作页只暴露横竖屏控件，**没有观察到分辨率、帧率、码率或片长选择器**。不能据此断言这些选项永久不存在；也不能声称在提示词写 1080p／4K 就会得到相应像素文件。首次有成片后，检查下载文件再记录网页的实际输出。

| 产品／资料 | 已有文档能力 | 对本技能的意义 |
| --- | --- | --- |
| Gemini 网页 | 10 秒宣传、横竖屏、参考素材、多轮修改、续接 | 按当前控件执行，硬性输出像素待实测。 |
| Omni API | 360p、720p，1080p／4K 为升采样输出 | 是 API 参数，不当作网页菜单；本技能不配置该 API。 |
| Google Flow | 有独立模型、片长和清晰度选项 | 是另一产品，不能把它的设置或额度当成 Gemini 聊天页面。 |
| 旧 Veo 教程 | 历史短片、镜头与声音描述 | 可以借鉴创作语言，参数与限额不能覆盖当前 Omni 网页。 |

API 的分辨率定义见 [Omni API 文档](https://ai.google.dev/gemini-api/docs/omni)；Flow 的独立支持矩阵见 [Flow 模型帮助](https://support.google.com/flow/answer/16352836?hl=en)。只有用户需要并授权改用这些产品时才扩展接入。

超过单段或可用续接范围的需求，要明确规划多个镜头及后续剪辑，不能承诺网页一次生成任意长度影片。Google 产品页说明生成内容带有不可见 SynthID 标记；下载文件是否另带可见标志，仍需观察实际成片。[Gemini 产品说明](https://gemini.google/overview/video-generation/)

“画幅”“像素”“文件大小”是不同量。16:9 不等于 1080p；同样像素的视频，时长、编码与码率不同，MB 大小也不同。平均总码率为 b Mbps、时长为 t 秒时，文件体积可粗估为 b×t÷8 MB，另有容器开销；这不是 Gemini 提供的固定输出承诺。用户要求特定大小或编码时，先检查原始下载文件，再在授权范围内转码并复核，标清转码与原始输出。

## 素材要求

视频创作专用的“最多 5 张图片＋1 段视频”优先于通用附件的数量上限。通用 Gemini 文件分析帮助列出单视频最大 2 GB、其他文件最大 100 MB、每提示最多 10 个附件；这些是**上传分析上限**，不保证同样大的素材能用于视频生成或编辑，也不是成片大小。不要把 Pro 可分析长视频等同于可直接编辑同样长的片段。[文件上传帮助](https://support.google.com/gemini/answer/14903178?hl=en)

本次未找到 Gemini 网页视频创作专用的完整图片像素、输入编码、FPS、码率和最大提示词字数表。不要编造最低尺寸、强制英文、固定 MB 或“所有格式支持”。使用前读当次文件选择器和上传校验；需要兼容性调整时，保留原素材，按实际错误处理。API 对参考视频／编辑输入的限制不能代替网页要求。

实践建议（非 Google 硬限制）：优先用清楚、无误裁主体且画幅接近目标的图片；参考图不要混用互相冲突的主体外观；先剪出真正要编辑的镜头。JPEG／PNG 图片、MP4 视频是可优先尝试的常见交换格式，是否接收仍以网页为准。

## 配额、可用性与失败

Google 当前采用计算量相关限制；视频属于高消耗功能，套餐、系统容量及滚动限制影响可用量。不要把网上“每天 3 次／5 次”等旧数字写为永久事实。当前剩余次数和重置时间以界面通知为准。[Gemini 限额帮助](https://support.google.com/gemini/answer/16275805?hl=en)

| 现场情况 | 处理 |
| --- | --- |
| 已登录但无视频入口 | 核对套餐、年龄／区域及入口变化；不把“已登录”当作有视频权限。 |
| 正在生成／操作工具超时 | 查看同一对话的状态，保留原任务，不重复点提交。 |
| 配额耗尽 | 报告实际提示和重置时间，不重复生成，不自动订阅。 |
| 素材拒绝／格式错误 | 读取具体错误，检查上传用途、长度和文件格式；不要重复上传整个无关素材库。 |
| 字幕、对白或细节偏离 | 针对实际问题修改；精确文字与说话内容需要成片核对。 |

用户素材只用于其授权任务。Google 对上传及生成内容有服务规则和过滤；这是处理实际拒绝的依据，不是额外添加无关审批流程。[网页视频帮助](https://support.google.com/gemini/answer/16126339?hl=en)
