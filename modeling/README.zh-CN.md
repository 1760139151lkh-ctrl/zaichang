## 坐标

Blender 单位为米：X 向东、Y 向北、Z 向上。局部原点 WGS84 为经度 120.085、纬度 30.3005。比例由脚本中 `SX=111320*cos(latitude)`、`SY=111320` 给出。这是局部示意坐标转换，不是新的测量精度声明。GLB 默认导出为 Y-up，导入时应由标准 glTF 加载器处理轴变换。

## 重建

需要 Blender 4.3.2，以及与其 Python 版本匹配的 Shapely 2.2.0 / NumPy。脚本中的依赖目录是本次云端环境路径，其他环境应改为自己的安装位置。

在项目根目录按对应局部说明运行其构建脚本。不要以旧 `build_campus.py` 重建结果覆盖当前逐组细化模型。

不要运行原地图导入器来替代本轮模型构建；本轮只读保存的地理快照，不重新抓取校园数据、模型服务或个人账号。
