\## 五、让整个 Harness 的主动性、工具协作和角色体验成熟起来\

\
其中，有几类问题需要重点处理：\
\
\- \*\*主动理解用户并调用信息。\*\*在理解用户、对用户建模时，助手能否主动获取空气等环境信息、GPS、日程安排和已有记忆，并把它们合理地用起来？能否根据当前需要主动调用工具，不必等我逐项提醒？\
\- \*\*主动深入记忆。\*\*如果当前问题需要进一步了解用户的某一方面，助手能否主动开启子代理，深入查找相关记忆，再把找到的信息用于后续判断和回应？\
\- \*\*把实际功能接进来。\*\*跑步次数查询等能力是后面可能需要接入的内容；日程规划这次就应该做。现有工具和未来工具要怎样分配、怎样接入、怎样被助手主动使用，都需要继续完善。\

\- \*\*调用与呈现的顺序。\*\*各项功能在什么时候触发、工具和技能怎样衔接、结果怎样被后续环节使用，以及最终呈现是否存在顺序错乱，都需要从整个 Harness 的角度理清。\
