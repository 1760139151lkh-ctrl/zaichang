### 五、第一条必须跑通的学生闭环

以明确合成资料或当前已授权资料：学生希望本周保留连续学习时间；已有具体课程与体育目标；朋友邀请晚饭；课程临时换楼；随后天气更新。

在没有额外“调用地图”提示时，系统从课程变化准备新路线；把约饭当未确认邀请，结合学习块和可行运动窗口形成合理方案；用户接受后写入同一日历对象；新变化只重算相关部分；完成或撤销后旧提醒结束。包含一次等待、一次静默、一次必要提问、一次用户纠正和一次在途取消。即使体育/校园自动源未接，也可用已明示的本地记录完成核心路径；未接工具不伪造成功。

同时验证用户举的运动例子：十二天还差三次、明天有雨，如果后来还有足够可行时段，就不能得出“今天必须跑”。课程表需具体 occurrence、假期/临时例外和来源覆盖，不能拿每周模板冒充完整事实。
