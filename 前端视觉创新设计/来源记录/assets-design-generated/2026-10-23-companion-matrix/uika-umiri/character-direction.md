## 八类动作：改变空间关系，而非只换道具

下列八个键沿当前 `src/shared/companion-activity.ts`；页面族 S1–S9 是另一维度，不增加为第九种动作。具体空间与来源登记仍等统一契约。每种姿态须在完整房间中建立，重心、髋部支承、双腿连续性与脚底关系独立检查。

| 情境 | 初华的表演方向 | 海铃的表演方向 |
| --- | --- | --- |
| `chat` 闲聊/回来 | 坐在窗榻前沿，髋部稳定，躯干轻转向人，手停在膝上；像听见最后半句后抬眼 | 在书桌椅上自然侧坐，肩膀朝人，双足在地，一只手掌轻压椅面、另一手停在膝上，干练地抬眼；不凭空添加扶手 |
| `study` 硬核共读 | 坐椅前段、略向桌面前倾，一只前臂真实落桌，视线沿同一张推导纸 | 椅上端正前倾，一手压住纸页、一手指向确切行位；注意力落在题上，不对镜头摆拍 |
| `reading` 阅读/批注 | 窗榻侧坐，后背获得靠垫支承，书靠腿而非悬空，视线随页向下 | 窗榻侧座，一掌压垫、一手托膝上书；从桌面前倾共读中真正退开，视线随页向下 |
| `planning` 安排/冲突 | 桌椅侧坐直身，髋腿向桌，上身明确半转回人比较两张小纸；不再用榻上 chat 加小本充格 | 保固定桌宽/桌灯，椅可小转，直身回看比较两份安排；不作已经执行的姿势 |
| `listening` 倾诉/试演 | 在窗榻上自然收拢双膝，完整说明脚的位置与裙摆覆盖，重心仍落在垫上，安静听完 | 一膝自然收起、另一腿有清楚支承，肩膀放松，身体偏向说话的人；不把倾听演成工作汇报 |
| `rest` 休息/望窗 | 身体整体转向窗，侧脸望外，手臂与座面形成稳定支撑；日间望天空，夜间才可看星 | 后靠座垫、腿部放松，视线离开工作纸望窗；保留利落轮廓，但不显得在等新任务 |
| `play` 整活/小发现/共创 | 吉他有真实大腿/手臂支撑，躯干与手势进入音乐姿态，吉他颈不越入正文区 | 贝斯落在大腿上，拨弦与按弦各有手部关系，颈朝画面右上；不只是抱一本书换成乐器 |
| `attention` 当前对象/新界面反馈 | 从侧座转回，轻递书签，目光接向当前对象；没有向人索取回复的表情 | 从桌边回身，将一张停点纸送到手边，保留利落半转身与轻微笑意；不做催办手势 |

初华的动作节奏更连续、耐心，视线从原文回到人；海铃的动作更简洁、准确，先把可用位置腾出来。两人的亲近都不靠露肤、夸张卖萌、成熟妩媚或固定微笑。

## 本轮生成与检查边界

四完整主题分别在同一空间几何下建立整幅环境与人物受光，不把一幅人物统一盖黑。每个缺格独立调用内置 Image；逐个保留真实 Prompt、唯一输入、输出路径/哈希、人物与家具支撑检查及主审状态。先产一个可亲看的候选并交主代理，再扩相邻格。主审前只记 generated，不记 approved；未运行的图不写成运行通过。

母图通过后，才在同画布提取人物/alpha/接触影并逐资产校准；不得靠分离修骨架，也不把官方站立图贴进房间。校准只进入各自的 `.scene.json`，来源 manifest 仅引用它和实际 Prompt/hash，不复制第二套校准。手臂落桌的姿态须缩小合法行程，避免一拖就脱离桌沿。
