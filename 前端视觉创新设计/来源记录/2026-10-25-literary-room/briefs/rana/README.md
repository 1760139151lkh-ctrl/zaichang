## 新基准里真正需要延续的东西

画面让人先感到有人住在这里：左侧书桌与书架有生活厚度，近处植物、木地板与织毯建立纵深；窗、湖、远城与山有完整关系；陶瓷灯和杯落在小圆桌上，窗榻软垫、格纹靠枕和针织物与人物共享光线。人物比旧 room4 更近，眼睛、发丝、握书时的停顿可以细看。留给活内容的空间要从新构图重新判断，不沿用旧房的像素槽位，也不先把这一张改造成空白 UI 背板。

将这种亲近与生活质感用于乐奈时，保留她自己的节奏。她会被某件具体的小事吸引，有自己的好恶，也能在你认真时认真起来。温度来自真实注意、愿意共享与允许彼此保有空间；表情不必每格微笑，沉默也不必每格忧伤。她的古怪要落在看见了什么、如何判断、怎样回应上。

## 原作依据与本项目原创分开

官方人物简介给出的依据很简洁：乐奈随性，兴趣与好恶鲜明，会被有自己主见的人吸引，音乐能力很强。[BanG Dream! 官方人物简介](https://bang-dream.com/artist/mygo/kaname-rana/)。官方动画页也将她写为自由出现、性情直接的乐队吉他手。[MyGO!!!!! 官方角色页](https://anime.bang-dream.com/mygo/character/rana/)。本轮取得了前者公开页面正文，并以官方检索结果交叉核对；未引入二手人物解读。

这些 brief 中的共同学习、倾听方式、日常停顿和情绪细节，都是**在场的原创演出推论**，不是原作剧情事实。音乐、猫或抹茶可有自己的位置，但本组不会靠反复抱猫、抱吉他或捧同一杯饮料确认她是谁。

外观沿已亲看的合格乐奈身份图：短银白 bob，柔软齐刘海与淡紫发梢；自身右眼金黄、自身左眼蓝，面向观者时对应观者左金右蓝；宽松黑短袖外衣、白长袖与白短裤、黑色系带踝靴。该身份参考来自旧合格 Rana 母图（SHA `26bf57f84c03de99efad34ec75a6abd759d484d29933b1830b36c15cabbff812`），**只用于身份辨识，不携带旧 room4 的相机、人物尺度、坐面、阴影或分层准入**。祥子新母图承载空间与文学气息，乐奈仍须有自己的脸、目光和衣着。

## 36 格共用的导演底线

每格先读文学情境，再看表演与身体描述。身体只需简明、可信：真实可承重的座面，手与物件在可达范围，手腕/袖口/膝踝连贯，完整鞋位服从具体家具高度。不可为图省事拉伸人物，或借原母之外的远桌让手隔空搭上去。学习与安排的具体工作位，等对应单祥子样板成立后再定。

双眼要有清楚的眼睑、虹膜与眉毛；前发自然分开，不粘成眼睛，不用发丝遮掉需要核对的五官。降低视线也保留可读的面部关系。人物受光、头发、衣料、座垫与投影共享真实环境，四主题不是整图套色；植物可保自然色，不产生绿色 UI 或全局染绿。

构图不增加活动按钮、路径轨迹、教程字样或功能面板。小物件是此刻事情的一部分，不是通用道具证明。生成图不烘焙用户正文、公式、日程或界面文字。

恢复、共读、倾听等故事只在真实对象和当下语境支持时采用。没有已保存停点就只重逢，没有已查询资料就不暗示准备好了；没有明确授权就不把画面里的安排当成真实日历写入。四套光照是创作意图，不是对现场天气或时区的事实声明。
