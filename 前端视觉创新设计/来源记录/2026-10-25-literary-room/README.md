# 文学窗边：新的共同空间

场景家族：`literary-room-v1`。日期：2026-10-25。

用户选择的是[最初的 text-only 文学阅读图](../2026-10-25-ambient-redesign/sakiko-reading-literary/sakiko-reading-apricot-literary-v1.png)，并明确要求“所有的布局都改成他吧。所有矩阵都要换一下。”本目录从这张图建立新的制作基线，不把后来回到旧 room4 比例的 v2 当作替代基准。原图、提示词和净空房的字节血缘见 [family-source-v1.json](family-source-v1.json)。

这是一份制作台账和设计 brief，不是新的运行时目录、权限库或产品控制面板。旧资产仍作为历史来源保存，其相机、家具坐标、分层、计数和实机批准均不自动迁入。

## 图里真正值得延续的东西

她在读自己的书，也给你留着靠近的余地。温暖来自有人照料过这间房：灯与杯子有自己的位置，布料顺着身体承重，书握得自然，窗外的水、屋顶与山有安静的纵深。她不是一直看着你笑的服务头像，也不靠夸张害羞、悲伤或摆姿势来表达亲近。

亲看原图可见，木窗比旧房间更高、更近，人物与家具更有生活尺度；她占右侧，左侧保留可供内容展开的空间。左边的书架、椅背、灯和叶片仍有细纹，长文不能直接压在这些纹理上。正文由真正的排版与克制的纸面承托，保留窗光和木头的气息，不用厚重白卡片把新房间重新盖掉。

固定的是这一家族的镜头关系、家具和居住感，不是把十个人都换成同一副低头读书的身体。九活动改变具体的参与方式；人物亲近、让位、兴奋、沉默与专注，都应与眼前共同对象有关。

## 九活动的共同边界

| 活动 | 画面应接住什么 | 不应冒充什么 |
| --- | --- | --- |
| `chat` | 自然接话，允许拿着刚才的书或小物 | 每句话都切一次姿态 |
| `study` | 眼前正在推敲的条件、步骤和图形 | 已替用户学会、提交或完成 |
| `reading` | 共同读到的一页，安静也有回应 | 闭眼或低头就等于已读原文 |
| `planning` | 可比较的真实安排和暂定取舍 | 接受、保存或实际执行 |
| `rest` | 允许歇一会儿，也允许继续认真做事 | 据表情诊断用户疲惫或强制休息 |
| `listening` | 跟随正在说的具体内容，不急着展示答案 | 所有人都需要悲伤安慰 |
| `play` | 小发现、纸鸟、共创和好奇心 | 玩具突然放大人物，或任意道具动作都已实现 |
| `attention` | 看向对方明确指的新对象，随纠正改向 | 追逐每次鼠标移动，或永久显示指示线 |
| `resume` | 当前真实书签、停点或尚未结束的共同对象 | 编造上次内容、自动打开或继续业务 |

姿态顺着原模型选择与话语自然发生，用户不需要九个活动开关。姿态意图回执不证明画面已经显示；缺素材时不能拿旧 room4 或别的天气人物凑覆盖。

## 天色、天气和手选主题

八板为 `clear-day / overcast-day / rain-day / twilight / dry-night / rain-night / time-day / time-night`。四主题是美术配色分类，八板是环境条件，二者不按下标相配。暖杏阅读原图只证明被选中的晴日画面；不能仅因一格叫 `mist` 就当成下雨，也不能把 `rain` 配色当成真实杭州此刻在下雨。

自动环境继续读现有 main 天气 owner 的有限投影：杭州固定公开参考点、`Asia/Shanghai`，不是用户位置。只有 `weatherEnabled` 开启、来源有效且当前天气未过期时，才按真实 condition、isDay 和日出日落选择已审核匹配的环境。晴朗白天不因清晨钟点落到缺暖杏活动的晨雾分类；夜晚无雨和夜晚有雨分别审核。风雪等没有对应板时，保持未知边界，不自行改成晴雨。

关闭、撤权、缺数据或过期后清除天气断言，沿原设置时区与 time-only 板继续；不得补报晴雨，不读 GPS，不由 renderer 另开天气客户端。手选主题保持手选，不冒充现场天气。环境变化须作用于窗外、室内反光、木头、人物和织物，不能只给界面刷颜色；夜间不能留一间白亮房，雨夜也不自动把人画伤心。

## 从新房间到全部真实页面

以下是完整迁移的验收准则；当前已观察范围另列，未观察的页面、布局和关系仍须逐项完成实际验收。

| 使用面 | 必须保留并迁移的关系 | 可观察的验收 |
| --- | --- | --- |
| 首页、空对话、普通聊天 | 新窗景、当前自然活动、会话与输入框 | 人物尺度不突然跳变，开始输入不失焦，返回仍是同一草稿 |
| 学习、陪学纸、推导 | 活文字、公式、真实步骤和共同选择 | 人物与光影退到内容之外，公式和操作可继续，页面不变成整图 |
| 资料列表与 PDF/长文 | 原文件、页码、选句和返回位置 | 长文有安稳底面；缩放、选字、翻页、引用仍通畅 |
| 笔记、日程、地图 | 原对象、修订、试放与真实镜头 | 配图不改业务，不把拖放、点选或看地图说成保存或到达 |
| OpenUI 与小发现 | 可玩作品、当前值、撤回与继续 | 纸鸟是适合大小的参与物；人物不为一次小发现突然靠满屏 |
| 休息、倾听与接续 | 安静的选择、真实停点和随时回来 | 不放万能安慰，不重播欢迎仪式，不强行劝退正在做的事 |
| 设置与陪伴预览 | 同家族、同角色、当前自然活动、完整环境 | 无九活动开关；试看/取消/采用互相一致，取消还原最新保存值与真实天色 |
| 头像、隐藏、自定义与减少动态 | 用户已选的出现方式与旧自定义数据可读 | 内置新图不替换自定义图，隐藏不闪回人物，少动态仍能读与操作 |
| 窄屏、文本放大、输入展开 | 正文优先、角色身份、可继续的操作 | 不把整张横图硬缩成缩略图；不裁掉头或手来凑空位。半身/头像/静态构图须单独设计与实看 |
| 等待、取消、失败与重入 | 同一对象、草稿、焦点及恢复入口 | 操作立即接管在途表演，重试不重建另一份输入，不以完成动画冒充业务成功 |

正式校准前不继承旧 room4 的 seat、floor、travel、hitPolygon 或 ROI。新[源坐标候选](geometry/literary-room-v1-grid.json)与[接入方案](geometry/literary-room-v1-integration-plan.md)只登记可见几何和计划，不是运行时校准或主审批准。先核家具、视线、尺度与文字区域，再亲看单角色跨活动；随后扩大十角色与主题。同一母图分离须保原 RGB、画布、真实接触和遮挡。需要手与物件配合时按实际层次分离，不硬规定恰好三层；结构错误的角色不能继续作垫图。

新家族的窄构图、眼神、递出、收回、退让和可中断过渡是独立未完项。正式使用前，root 应亲看最终页面并真实操作相应变化；静态图、台账齐全或构建通过均不能替代这一步。

## 产品里留下什么

让书、手势、留白和真实内容说话。内部格子数、SHA、分层、准入、队列、能力接线等词留在制作记录，不写进产品主内容。按钮命名实际动作；没有必要的提示先去掉，再看使用者是否仍能自然理解。全界面不使用绿色控件或全局染绿，原作服饰与自然植物保其固有色。

本次台账更新未修改旧 catalog、`src` 或其他并行文档，没有新增测试、运行器或子代理。图像制作与实机观察各沿自身来源记录登记，不以台账代替原图或运行回证。
