# D01 祥子窗台局部动作包

这组资产只服务现有 `sakiko-chat-apricot-room4` 的“看向—改看下一行—输入让位—收束”，画布始终为 1536×1024。

当前阅读姿态使用另备的[同源reading动作包](reading/README.md)。两套分别注册，不能为了显示动作改变用户当前活动或把聊天头/臂贴到阅读母版。

- [rig 坐标与轮廓](sakiko-d01-rig-v1.json)直接对应 `CompanionD01Rig`。母版、身体根、窗台支撑与另一只撑手保持固定。
- [右臂补洞板](sakiko-body-clean-right-arm-v1.png)只在 `arm.erasePath` 内使用，补回原手后面的书面和衣料。
- [眼白底板](sakiko-eye-white-clean-v1.png)只在原眼睑开口内使用。原虹膜随后从母版取回，不能单独展示这张无虹膜的脸。
- 上臂、前臂与手、头部和虹膜均取母版原像素，由渲染器的局部路径控制；没有重画手眼，没有裁掉全画布外边距。
- 书的前缘与领口另作遮挡。右腕先以约12–20像素的轻抬幅度观察，眼球位移不超过约2像素，头部仅作约1度的轻跟随。实际看向由虹膜完成，整头倾斜不能代替视线。

两张生成底板的非局部像素有轻微变化，因此不能整图替换原房间或整个人。全部输入、输出SHA-256、原提示词、生成回执、静态观察和限制分别记在对应 `.source.json`。

`quarantine/` 中两张透明手臂提取均被拒用：它们改变了原手臂大小和位置，并带有软透明光场。第二轮同类失败后已改用原像素裁切路线，不再重复该提取方式，也不将失败图用作后续参考。这里没有运行时通配入口。

当前已亲看母版、父看向候选、同景空背景与两张补洞板；轮廓经过原图位置和只读像素观察定位。最终重组、关节接缝、书面接触、眼睑限制、头/后发与领口，以及中途让位仍须在集成画面中亲看。`motionVerified` 和 `inAppVerified` 保持为 `false`，不能以这份资产包代签完整动作。
