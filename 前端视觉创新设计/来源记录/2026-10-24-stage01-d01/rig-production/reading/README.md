# D01 当前阅读姿态的局部动作包

本包只对应实时确认的 `sakiko-reading-apricot-room4`，沿 [原校准](../../../../运行素材/companion/scenes/sakiko-reading-apricot.scene.json) 保持1536×1024画布、靠枕/后背与髋部支撑、交腿关系和零根位移。不能换成聊天姿态挂动作，也不借用聊天图的头、手或虹膜。

[rig数据](sakiko-reading-d01-rig-v1.json)登记以下三张局部资产：

- [完整右臂源板](sakiko-reading-right-arm-unoccluded-v1.png)：只移走书，补出原来被遮住的右前臂和完整手。只取右臂纹理；全图不显示。腕在约1282,515，1253,515是指端/书接触，不能把指端当腕关节。
- [书面修复板](sakiko-reading-book-repair-v1.png)：暂时移除两只手以修好原指后的书页、书边与衣料。实际只采旧右臂修复区和书前景，再盖回原母版的固定左手/前臂；左手区域的生成变化不进入画面。
- [眼白底板](sakiko-reading-eye-white-clean-v1.png)：只取原眼睑开口里的眼白。原虹膜从阅读母版取回，在眼睑遮罩内有限移动，头部约1度轻跟随。

动作顺序为右手先松开原书缘、做小幅示意、收回并接原书边。左手和膝面一直保住原书的位置、角度和支撑；书不随右手走。`sourcePose` 的肩/肘/腕与原姿态同坐标登记，不以缩放补救错误比例。干净书前景来自修复板，原左手来自母版，不能用原整书连带把旧右指重新盖回。

`quarantine/` 四张失败图不参与运行或同步：两次直接抬手都留下旧右手而成为三手；两次单手擦除没有真正擦净旧指。失败图从未作为后续生图参考。分别保留原提示词、输入/输出SHA、观察和换路线理由；后续回到合格原母版，改为“移书补全原手”和“无手书面修复板”后成功。

03和04已亲看三板与母版。实际重组、关节、书/手遮挡、转眼、改目标及输入中途让位仍等当前阅读组件亲验；`motionVerified`、`inAppVerified`保持false。父级聊天包也保留，二者按各自母版选择，不交叉套图。
