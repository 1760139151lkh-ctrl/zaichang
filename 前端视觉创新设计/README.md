# 在场图片

图片统一存放在本目录。按主题找图见[统一图库](统一图库/README.md)，精确尺寸、文件大小、哈希与来源见[图片清单](统一图库/catalog.json)。

## 分类

- `统一图库/原图/`：110 张在场设计与素材原图，按对话、学习、日程、设置、人物窗景、纸面装饰、品牌等主题分目录，同步当前私有 GitHub。
- `统一图库/仅本机/原图/`：1,260 张实际页面截图、交互讲述参考和历史页面，按页面主题归类。
- `来源记录/`：原生成分组的 manifest、提示和采用记录，随图片一起收拢。
- `统一图库/仅本机/来源清单.json`：全部 1,370 张图片的原路径、会话或 ZIP 成员证据；`完整目录.md`提供本机分类目录。

## 整理规则

只收在场图片。核查九宫格、联系拼图、非在场图、独立地图工程／调试／路线对照图不收；原始设计稿自带的 A/B、桌面／手机排版保留。完整在场设计或讲述页面里出现的地图保留。

每个 SHA-256 只存一张，文件名使用可读主题加短哈希。核对原字节后删除散落原图和重复副本，应用和文档引用一起改到集中路径；原生成文件身份继续记在来源记录中。两张透明边缘有彩色残留、没有产品引用的失败纸材已清理，生成日志中的历史结果仍保留。

本次由八个实际 `gpt-6-luna / max` 子代理分查生成目录、当前及归档会话、仓库、ZIP、外部散落目录和 Git 历史。初扫 70 张 Codex 生成图，其中 68 张在场图均有生成结果字节证明；排除非在场图、失败纸材和后续明确不要的地图／核查图后，以当前图库为准。全部图片保留原字节，没有裁切或重编码。

原始研究 ZIP、原话和其他项目的活跃工作树保留；私人页面截图和完整来源记录留在本机，不进入公共地图或安装包。私有 GitHub 备份不授予新的公开分发权，图稿也不代表功能已经实现或验收。

设计含义继续查[原始讨论](图片来源对话.md)、[图像与页面对应](图像与页面对应.md)和[各轮设计采用](../FRONTEND_DESIGN.md)。
