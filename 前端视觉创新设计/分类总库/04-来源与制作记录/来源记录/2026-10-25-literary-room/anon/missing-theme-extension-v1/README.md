## 逐图实际观察的共同结论与限制

16张工具完整原图均在生成当时亲看。候选中倾听是双手安静落膝、合册在身侧，视线接住仍在说话的人；轻玩是掌心托小船、另一手调折角，笑由具体小物与对方接招而来；注意是一指保页/书签、另一手托册，眼神先回应轻唤；接续在右阅读位保同一材料意图，认出同伴后小幅转回书页。所有画面只有一人，没有向空气硬指、灰板或准备完成声明。

**轻玩物件保“小纸船”。** root亲看准入的原play确切submittedPrompt写BOAT，原图也是船，十二格里的精确play brief允许小纸物；旧计划existingProjectDirection的一句纸鸟不覆盖这件已成立实物。没有把好物件拼换掉。部分纸船仍举胸前，较brief膝前略高，手腕承托可读；此项已如实记source，不以活动名替具体物理关系背书。

夜图不只看雨玻璃。复看了软垫、人物尤其膝面、衣料和地板；所选纯plate夜稿的原硬白日斑已退出，人物在局部柔暖灯和低蓝窗光中，远处软垫/地板降暗，未见明确白昼窗格硬阳斑。倾听雨夜原v1的膝面柔散、未见同类硬白块，保候选而不为躲审重产。所有新图仍由root亲看，不用producer独看代签。
