# 在场图片分类总库

这里集中保存本轮已经迁入的图片原件。不同构图、姿势、尺寸或细节的版本分别保留；只有内容完全相同的文件才合并。旧会话若仍需要原路径，会通过文件系统硬链接指向同一份文件，不再保存第二份图片数据。

| 分类 | 内容 |
| --- | --- |
| [程序素材](01-程序素材/) | 人物、场景、纸面、头像、品牌以及近桌共读素材；具体引用仍以代码和场景登记为准。 |
| [精选设计稿](02-精选设计稿/精选图稿/) | 既有 A 标杆、B 微调复用、C 交互基因，保留原有分级。等级是设计评鉴，不等于功能已经实现。 |
| [补充设计稿](03-补充设计稿/补充图稿/) | 后续补画的页面、场景和比较图。 |
| [来源与制作记录](04-来源与制作记录/来源记录/) | 按批次、角色和场景保留原始图、分层、蒙版、提示词及配套记录。 |
| [图库候选](05-图库候选/统一图库/) | 早期图库、候选图和本机资料；其中本机资料继续遵循原有忽略规则。 |
| [过程核对](06-过程核对/仅本机/) | 制作、分层和局部检查过程中的材料。 |
| [历史运行证据](07-历史运行证据/历史运行证据/) | 旧版本运行截图及对应的视觉观察资料。 |
| [本机历史截图](08-本机历史截图/) | 从工作目录归位的历史截图；可能包含私人内容，按 Git 忽略规则留在本机。 |
| [对话中找回的原图](对话中找回的原图/) | 本轮逐张查看并归位的会话原件，分为界面、场景、人物、蒙版和过程核对；当前仅保留在本机。 |

原有[深度评鉴](../2026-10-23-深度评鉴/README.md)保留逐图判断和历史来源；[视觉资产入口](../README.md)提供整体背景。云端对话附件和历史淘汰图片的可访问范围，以本机整理说明为准。
