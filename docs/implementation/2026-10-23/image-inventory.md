## 逐图入口

完整本机导航位于被 Git 忽略的 `前端视觉创新设计/统一图库/仅本机/image-inventory-2026-10-23/`：

- `review-order.json`：182 张图的编号、原件路径、尺寸、模式、SHA-256、重复来源和待亲读标记。
- `review-simple.json`：兼容旧清单读取方式的 `id/path/title` 三字段简表。
- `READING_INDEX.md`：按编号打开各原件与观察联系表。
- `original-numbered-series.json`：最初 1–22 的确切对应。
- `five-references.json`：五参考与 `V145–V149` 的对应。
- `zip-images.json`：64 张 ZIP 图片的成员名、原字节 SHA、CRC 与现存原件。
- `file-receipts.json`：全部检查过的文件路径及 UTC 文件创建、修改时间。
- `contact-pages.json` 与 `contact-pages/`：46 批观察表，每批最多四图，每图按完整比例呈现，图像区域宽 810 px。联系表仅作观察导航，不入原图库，不替代关键原图查看。
- `pixel-duplicate-groups.json`：解码像素相同但原字节不同的组，独立于原字节去重。
- `observation-renders.json` 与 `observation-renders/`：ICO 原生解码与 SVG 矢量渲染所得本机观察 PNG，附原件及副本 SHA；不进入产品或 Git。
