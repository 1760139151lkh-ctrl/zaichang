# 灯：同一扇窗的三种相处状态

按已通过的祥子房间网格横向扩展，不另设人物坐面或页面布局。先亲看灯闲聊母图、祥子共读母图与雨夜母图，以灯的短灰紫发、金棕眼、灰制服白滚边与深绿条纹领带固定身份，再分别生成共读与夜间完整场景。

本轮五张均使用内置 GPT Image。母图生成后再次逐张打开；随后分别从灯闲聊、共读、夜间三母图提取同幅 figure，再逐张打开检查。所有文件保持工具原生输出，没有裁切、居中、重采样、调色或代码抠图。

| 文件 | 场景与检查 |
| --- | --- |
| `tomori-reading-mother.png` | 同一日间窗、湖与钟楼、坐面、软垫和左侧留白；灯低头共读，完整双手、腿和鞋脚可见。 |
| `tomori-night-mother.png` | 同一雨夜与暖灯，灯捧杯，完整坐姿与鞋脚保留；不将昼夜切半。 |
| `tomori-chat-figure.png` | 从既有灯闲聊母图提取，保留手中小石头与线圈本。 |
| `tomori-reading-figure.png` | 从新共读母图提取，包含打开的书。 |
| `tomori-night-figure.png` | 从新夜间母图提取，包含杯子与双手。 |

五张均为1536×1024；三张figure是具有真实alpha通道的RGBA。提取图存在低alpha光晕，前端沿现有SVG alpha transfer抑制边缘晕层；**figure的RGB绝不作为产品人物显示，显示内容仍取对应母图原像素**。图像尺寸一致不等于逐像素分割已经验收，最终同窗合成、移动边缘和坐面贴合由主代理在真实界面继续亲验。

背景按主代理规范复用对应祥子cleanplate：日间/共读/夜间不因角色新增而各造一个房间。没有修改任何其他角色资产、背景或源代码。
