# 同一扇窗：本轮视觉与交互标尺

主代理亲看本次5图、压缩包64图和全部分支设计资产；SHA去重后184张，逐图地址另见图稿对应表。原始22图与《图片来源对话.md》第一行及全文已分别阅读。历史图里的旧角色、工程文案、错误数学与示意地图不作为现行产品事实。

| 场景分类 | 先看什么 | 画面与空间 | 直接操纵及返回 |
| --- | --- | --- | --- |
| 回来/闲聊/休憩 | 问候、已有草稿和继续入口 | 左侧稳定纸面，右侧同一窗边完整场景 | 人物沿真实坐面短距移动，取消归位，持久保存 |
| 原文/共读/学习纸 | 原文、选段、同一问题 | 正文优先，两纸共用顶线，人物退到页边 | 连续分屏、精确原文拖入聊天、同笔记批注改锚 |
| 今天/方案试放 | 当前日期与真正的安排 | 一条时间线、当前对象详情，无常驻角色大图 | 试放重排、明确碰撞、找空档、原对象确认及撤回 |
| 留下/资料/回源 | 当前文件或笔记正文 | 轻列表与稳定正文，不另加服务卡墙 | 引用保身份、原文来回、恢复旧稿 |
| 路线/地图/取景 | 真实地理和选择 | 同一个地图画布与相机 | 连续展开收回，手势接管，选择回原输入 |
| 角色/光线/主题 | 可比的同槽位预览 | 相同尺寸、相同人物坐面与相同控件 | 明确换形象与是否采用人格、四配色持久化 |
| 暂停/恢复/等待/失败 | 已写的话与可继续的位置 | 沿原页面出现，避免第二层常驻状态面板 | 可中断、保稿、按原身份恢复 |
| 主动准备/来信/好奇/共创 | 实际准备的内容 | 图文沿原对话展开，纸面与有限景物 | 接回同一对象、可收起与停止 |

公共几何：保留72px顶栏、中央三项导航和已有对齐控件。正文阅读宽以800px为上限；1440px窗口左侧阅读安全区延伸至约60%，右侧窗景自62%进入，二者之间保留渐变过渡但不设置昼夜分隔手柄。1024px以下先给正文明确纸面，窄窗采用同一场景的小幅陪伴区并保持输入可达。原题与推导纸沿既有约32:68默认比例，连续可调；资料与聊天保留各自分屏偏好，不将打样图58:42当作所有工作台的固定值。地图只在手势或明确观看时扩展。正文不穿人物、植物、窗棂。

角色只采用MyGO!!!!!与Ave Mujica内置角色，首批祥子/睦/爱音/灯；旧自定义人格和个人图片的数据保持可读。二维清晰线稿、青春面容与正常人体比例，避免成熟写实脸、短截无脚、荧光抠图边。采用完整场景母图先定透视、接触点、光向，再以Image分离同幅人物/背景；不把独立立绘硬套进旧房间。场景所有层共享裁切坐标，人物与持物沿坐面轨道移动并做轻微透视缩放；当前没有独立生成的接触影层，不宣称完整物理光影模拟。学习时换实际共读动作，内容空间优先。

四主题：暖杏、晨雾蓝、暮色紫、夜雨暖金，使用同一控件和尺寸。绿色仅属于窗外自然景物和植物，不作为UI强调色。昼、暮、夜是完整光线状态，禁止日夜切半拼接。动态使用可打断的位置过渡和即时拖动，减少动态时直接落位。

管线：先分类和标尺 → 祥子跨闲聊/共读/夜间的同网格打样 → 主代理亲看通过后扩展睦/爱音/灯 → 同槽位填入，实开比较。已有合格设计稿继续复用；不为生成数量重复造页面，也不以图像存在宣称功能完成。
