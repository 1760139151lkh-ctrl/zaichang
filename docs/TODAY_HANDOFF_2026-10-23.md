# Today 时间轴交接 · 2026-10-23

用户要求立即保存并合入 main，本段按已完成的实现和实际检查收束；不等同于全产品最终验收。

## 已落地

- `src/renderer/Workspace.tsx`：页头改为紧凑的“今天 / 这一天”与日期；日视图可切换时间轴和原列表；全天、未定时长、重复安排继续使用已有列表与编辑入口。
- `src/renderer/AgendaDayTimeline.tsx`：以真实起止时刻绘制日时间轴；显示时区的日边界支持 23 / 25 小时日；跨日安排裁切显示。课程是只读来源，不变成本机安排。
- 只有已保存、非重复、有明确起止时间且完整落在当前日内的个人安排可拖动。拖动实时跟随，15 分钟吸附，保留原位置虚线；Escape 取消。键盘方向键每次 15 分钟，Shift 每次 1 分钟，回车打开编辑器。
- `src/renderer/LifePanels.tsx` 的 `AgendaEditor` 增加 `initialStartsAt` 草稿和 `onSaved` 回调。试放没有写入；原始对象及版本保留用于前后对照；确认仍走已有 `api.action({ action: 'save', item })` 与宿主 CAS。
- 保存后可撤回挪动。撤回重新读取同一对象的当前 revision；不同版本不覆盖，保留原时间供用户判断；正常撤回只恢复时间字段。
- `src/renderer/today.css`：日期导航、时间轴、拖动阴影、虚线原位、窄窗与减少动态样式。

## 真实检查结果

在已有隔离 Electron 实例 `9222`、真实 renderer/host 之间操作，未替换 bridge。

该实例当前是**示例模型**：普通对话请求日期后返回通用示例卡，没有理解所请求的日期。随后通过该卡现有的“调整一下 / 加入我的安排”UI，明确填入测试标题和时间，再用原日程编辑器调整时长。以下是界面及宿主链路检查，**不是 Luna 模型检查**。

测试安排：`阅读讲义（交互检查）`，本机对象 `1238b7ec-54e0-4678-96f3-545736db97c3`，北京时间 2026-10-24 10:30—11:30。

| 操作 | 实际结果 |
| --- | --- |
| 指针拖动 45 分钟 | 卡片跟随、原位虚线出现；宿主 revision 保持 2，没有提前保存 |
| 松手打开编辑器 | “原来”10:30—11:30，“现在”11:15—12:15；原对象和 revision 未改变 |
| 确认保存 | 同一 id，开始时刻改为 `2026-10-24T03:15:00.000Z`，revision 3 |
| 撤回挪动 | 同一 id，恢复 `2026-10-24T02:30:00.000Z`，revision 4 |

| 430 × 900 窄窗 | 时间轴可见，document/body 宽度均为 430，无横向溢出 |
