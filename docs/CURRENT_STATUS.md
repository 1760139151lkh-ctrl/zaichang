# Current status
This repository contains the complete implemented desktop product and the integrated V3 map. It is not a promise that every historical aspiration is implemented.

Implemented: desktop chat/history/cancellation; host capability and permission routing; pinned Hermes engine/stdio; evidence and conditional derived memory with correction/retirement/forgetting; local calendar actions and reminders; TXT/MD/PDF material reader; native image input; campus read adapter; public web research; fixed-city weather adapter; shared spatial map, named-place selection and walking candidate routes.

The campus adapter requires a separately installed and privately authenticated connector; code being present does not prove a current user's university session or every paginated resource. No account snapshot is in this repository. Field completeness, current exam publication, GPA/retake policy and campus-card units must be verified against real resource contracts. Search transport success does not guarantee search quality; dynamic scripts and OCR are not implemented.

Real university booking/course submission/payment, email/DingTalk sending, mobile GPS/health/sync and speech capture have no completed production service chain. OS notification submission does not prove delivery, and closing the app does not guarantee reminders. The entire chat database is not encrypted. Native window dragging and some system scaling/IME behaviors need separate hardware checks. Automatic full-file UI retry remains limited.

Memory semantics and long-term model judgment are not certified by deterministic tests. Earlier semantic acceptance failures are not converted to success by this repository's build. Current checks verify mechanism and data isolation at the reviewed commit; new live model claims require their provider/model, date and exact source version.

The map is a 2026-09-10 public-source snapshot with project V3 display refinements. Door access, opening hours, construction changes, exact roof heights, some southern banks and complete indoor routes remain uncertain. Dashed access is an estimate; the sport markings are illustrative. WebGL fallback is planar and cannot provide a spatial camera. Review has no device location or personal bindings. Its existing theme is applied before data loading so loading, errors and the completed map share the same theme.

The mesh path rejects exactly collapsed triangles in its actual Float32 draw coordinates, while retaining thin and open surfaces. Repeated roof faces no longer cancel their outside rim. Exact source structure maintenance unifies internal shared polygon boundaries while retaining occupied areas, source members and all entity IDs; it also supplies the island generator's 15 missing detail parent IDs. The shared loader retains compatibility with the older omitted fields. A source-history road can contain ordinary and conditional segments; its runtime display follows default graph segments instead of hiding the entire way, while the original source and all graph edges remain intact. Display unions compose existing source and wing polygons in the same calculation frame to avoid a boundary fold on export. The importer preserves recorded width and mode access tags as source metadata, independently of screen line widths and current access verification. The planar renderer draws route halos below all foreground segments so known-road segments remain visibly continuous, while estimated access retains its dashed style. These repairs do not certify source shapes, heights, image registration or full-map coverage.

Ground road strokes draw subdued surrounding roads before campus roads, so their round ends do not cover campus continuations at shared junctions. The planar fallback uses the same priority and draws bridge casings below bridge foreground strokes. This changes display order only; road coordinates, recorded widths and routing remain unchanged.

MapLibre ground fills use uncut local Float32 triangles instead of independently simplified integer tile rings. Existing shared junctions within a declared sports venue are inserted on both derived boundaries before triangulation; source files and physical dimensions are unchanged. The same triangles drive fill picking, including courtyard holes. The existing cartographic colors, opacities, layer order, camera and planar fallback remain in use. Native outlines and extrusions, source accuracy and the remaining all-map factual gates require their own checks; this renderer repair does not certify them.

The planar fallback centers A/B letters inside route endpoint markers and places the corresponding name above the same endpoint. A missing or mismatched route retains the selected place's own anchor and role prefix. This separates the two labels without changing source coordinates, routes or ordinary place labels.

Pedestrian road polygons now use the shared paving color in both renderers, with all source holes retained. Their boundaries stay distinct from road centreline strokes. The Canvas style cache separates geometry types so a same-tag road line cannot inherit a polygon fill. Source coordinates, measured-width claims and routing remain unchanged.

Sports surfaces share their existing role-based colors and opacity across the spatial map and Canvas fallback. The fallback no longer applies dark literals in the light theme, and its cache keeps tracks, court groups, runoffs and indoor venues distinct.

An explicit inactive bridge tag in the source becomes a separate runtime route condition, alongside any gate-opening condition. Hypothetical routes retain that uncertainty and identify the historical bridge location in their warning. The loader preserves all nodes, edges, distances and original bridge flags; a historical tag is not a present-day access or structure survey.

Repository verification covers deterministic host/memory/route mechanisms, the actual pinned Hermes engine with synthetic host responses, native Windows desktop startup and the patched native PDF reader. Live model semantics and real university-account results are not certified by these checks.
