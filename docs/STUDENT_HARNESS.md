## 已集成的学生生活入口

- **记事本**：桌面 `NotesPanel` 与聊天工具 `manage_note`。原文、全文搜索、分页、编辑冲突、历史版本、撤销及回收站独立于日历和人物记忆；保存想法不会自动排时段。原验收通过“更多 → 记事本”进入。
- **角色**：设置中的 `PersonaEditor`。三个预设与自定义支持本地例句预览、保存、恢复及纯角色模板导入导出。关闭个性记忆仍保留角色；例句不是实时模型结果。原验收使用“连接与偏好 → 偏好”。
- **持续托付**：`manage_attention` 保存用户明确的范围、来源、期限和停止条件。来源变化、尚未关联的新变化与已知时间节点进入同一主模型判断；模型可准备、等待、询问、提示或结束。角色不扩大权限。
- **规划**：`situation.read` 按真实来源范围读取有界当前状态；日程实例保留原 UTC，同时提供声明时区的明确本地开始/结束，未知结束不补造。`planning.preview` 计算冲突和未知条件。邀请、愿望、未接受方案不占用已接受承诺，也不自动建立提醒。修改方案绑定原对象版本，点击接受后修改同一对象；撤销恢复原版本内容并产生新修订。
- **出行与天气**：现有公共校园步行图提供路线材料、地图版本和起点质量。没有设备位置时可用明确手动起点。`weather.lookup` 支持杭州、紫金港公开参考点或明确公开坐标及时间窗，区分日级与小时覆盖；WeatherScene 仍是日级展示。预测不是现场观测。

## 本轮后端加固与尚未放行的范围

这轮继续服务个人生活，而不是要求用户成为记忆管理员或自动化工程师。助手应主动读懂已经托付的事情，先查能查的资料、保留未知、做有用准备；不以通知更多、工具调用更多或给每段情绪排任务来证明积极。

规划采用已接入 `prepare_action` 前置校验和 `LocalCalendarService.apply` 保存事务内复验：完整参数、保存单位顺序、整份日历指纹、身份/策略、范围、期限和条件必须仍成立。准备/收尾并入工作占用，转场/休息及显式保护窗口另有实际保存单位。只有外层事务成功提交后才推进票据；回滚不推进，进度记账失败也不能把已提交动作改报失败。每一步有真实回执，失败保留并报告已完成部分，不把多个独立动作说成整批原子提交。既有单对象修改仍带原 ID/revision，不能以同名新建代替修改。

票据只在当前进程内，最多保留 50 份，有效期取 15 分钟与原 scope 截止中的较早者。重启或失效后必须读取真实日历重新规划，票据不存在不代表之前没有成功保存。外部当前版本解析器尚未连接，因此含不可复验外部具体引用的方案可供比较、不可采用；未知条件也保持阻断，不能把学校或设备资料换个标签当作已核实。

经受控动作链的普通本地保存同时检查近期草案被移除 `planRef` 的常见复制，检测范围是同进程最近 50 份方案、相同身份范围以及标题/开始时刻/类型摘要。它能拦截参数相同的脱离方案，不能保证识别任意改写，也不跨重启；带 `planRef` 的保存则必须完整匹配已核查单位。这是明确的工程保护范围，实际模型是否始终保留引用和正确处理部分失败仍须验证，不能先写成全部验收通过。

本轮严格后端先行。类型检查、SQLite机制与合成 Hermes 回调通过后，仍须补真实模型选择工具、记忆长期连贯性、角色稳定性和实际外部连接证据。当前环境没有完成本轮真实 Luna 验收，不能借用下方历史回执宣布全部后端可靠。本轮不新增前端页面；相关后端与失败恢复门槛通过后，新页面先按设计理念用 GPT Image 生成方案，再实现和实测。现有图片不证明手机/平板功能已经实现。

## 核心联动的当前契约

涉及模型的交互沿同一主 Hermes 循环运行；记事本和角色编辑器的普通本地操作直接走宿主业务入口，无需模型。两者共用宿主权限和持久状态。场景和时间线用于验收语义判断，没有作为生产主题分支或关键词通知表。下表保留本次学生 Harness 需要持续遵守的集成点，通用机制详见架构文档。

| 联动 | 当前实现要求 |
| --- | --- |
| 变化与恢复 | DomainService 的 upsert、删除及完整快照 tombstone，笔记 `note_attention` 和日历 `agenda_attention` 连接持久 journal/cursor/ack。日历同值写入不出新事件，回滚不留变化，删除/恢复保持单调版本；不用可选 probe 替代真实本地写事件。 |
| 元数据与正文 | 笔记事件不复制正文；日历事件不复制 title/detail/自定义地点文字。需要时按当前来源权限回读。无关注消费者的本地日历写不额外变成聊天证据；暂停或暂不可读的消费者保留待恢复，不挡其他可读关注。 |
| 持续理解与准备 | 广义托付的来源必须足以支持后续准备。初始发现、陌生有效变化和时间节点进入同一主模型；来源值不变时，材料过期或等待刷新仍可产生一次重评，不延长旧证据。持久 deadline 调度与失败退避负责何时再看，不硬编码生活场景。 |
| 停止与管理 | 关闭记忆后仍能按名称管理本人现实私有关注，主机执行停止不依赖旧聊天读取许可。管理元数据不带旧原话；后台按托付实际授权片段读取。当前关闭记忆时排除历史/人物来源，明确获准且仍可读的其他来源保留。 |
| 材料与真实呈现 | 准备绑定真实来源、对象版本、细分权限和时效。`inspect_help` 先发现轻索引；前台精确 `helpRefs` 引用由既有组件展示。正文实际可见才记 `displayed`，发现、读取、生成不算展示。拒绝、暂停或撤回后，迟到信号不复活旧材料。 |
| 规划与提交 | 邀请/愿望/提案和 accepted 承诺分开；只读预览返回原对象版本绑定的提案。当前委托核验或点击批准后才走动作提交；独立明确提醒不被可选主动性预算取消。 |

聊天留存、资料读取、模型传输、笔记保存和日程动作分别控制；整轮限源与某项托付/草稿的局部限源分别核验。“仅在本机”在云端预检前生效，当前没有离线模型；禁止网页搜索不自动禁止已配置模型。旧 guidance 中的混合私人经历不进入常驻角色。普通记忆的更正、SUPPORT 和遗忘在提交事务内重验依赖。

工具缓存、等价纯数据读取的在途共享、上下文复用和供应商缓存分别核算，每位等待者独立取消并复验权限。子代理使用实际编译的收缩上下文、共享预算和版本依赖，父任务负责采用结果。地图模型副本保留业务条件和距离，完整几何仍由现有 Scene/地图绘制；原始读取字节与模型可见 token 分开计量。上述机制不证明任意服务当前在线或任何新前端改动已经验收。

`unknown`、系统提交、来源送达和用户已看分别记账；先核查未知结果，不盲重发。迟到回执不重开取消工作。桌面通知当前只能证明 `submitted_to_os`。退出桌面进程后轮询停止，重开按持久状态恢复；这不等于手机持续运行或实际送达。

## 迁移与回退

笔记增加 `h_notes`、`h_note_versions`、`h_note_operations`，复用现有 SQLite 事务和 outbox。旧业务对象不补造来源、发生时间或授权；没有 planning 元数据的旧日程保持原先已登记/固定语义。新笔记中的主体与有效时间默认未知，内容不会自动生成身份判断。

本轮数据库 schema v6 增加 `h_source_restriction_spans` 和 `h_memory_recovery`，分别保存更正范围定位与恢复尝试，不另存一份私人正文。旧更正缺失范围时保留明确未知，不能编造位置。旧版程序不理解较新 schema，不应直接打开升级后的数据库；升级、回退和恢复继续遵守当前隐私屏障。

人格惰性迁移保留五轴设置；旧 guidance 原文保存在私有 `legacy-private-guidance`。确定的纯风格可迁入角色，混合内容不自动迁入预览或导出。角色和导入使用预期版本，恢复会生成新修订，不覆盖后来的修改。

升级前关闭应用并保留完整私有数据目录（SQLite、WAL 和权限/遗忘屏障），不要只复制单个数据库文件。业务撤销和角色恢复优先使用当前界面；回退旧程序前保留升级后的完整目录。旧版不理解笔记新表，其清数据功能不能保证清除新版数据；不能通过恢复旧备份绕过当前遗忘屏障。当前新版清数据/导出已包含记事本责任。

## T8：手机与外部连接的实际边界

当前没有 Android 工程、手机同步 API 或已部署持续宿主。原验收环境检查未发现 PATH 中的 adb、Android 环境变量或标准 SDK 目录，因此没有宣称真机通知、定位、锁屏和进程终止恢复通过。Windows 定位仍明确 `phoneConnected:false`。5173/5174/4173 是本机开发/公共地图端口，Luna 的随机 loopback 端口只服务单次模型传输，均不是手机同步接口。

现有接缝包括 ClockPort、DeliveryPort、Node SQLite、模型/工具回调与 Hermes Python stdio。可行的后续拓扑是 Android 承担本机提醒、通知、授权定位和离线起点，用户选定的持续宿主运行同一 Node/Hermes/数据层，按事件、版本、owner 和 fence 同步；这只是可行性结果，尚未部署。手机本地 Hermes 还需独立证明 Node/Python/SQLite/原生模块与后台生命周期。

Android [WorkManager 周期任务至少 15 分钟且受系统调度](https://developer.android.com/develop/background-work/background-tasks/persistent/getting-started/define-work)，[精确闹钟](https://developer.android.com/develop/background-work/services/alarms)、[后台前台服务启动](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)、[后台定位](https://developer.android.com/develop/sensors-and-location/location/permissions/background)、[通知权限](https://developer.android.com/develop/ui/compose/notifications/notification-permission)各有自身条件。后续需在真实 APK 上分别操作授权/拒绝、退后台/锁屏、离线重连、普通进程终止、force-stop 后重新启动和设备重启，不能承诺 force-stop 后继续后台执行。

[官方 ChatGPT app-server 登录路线](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server)要求应用自己的授权、令牌续期与撤销，以及所选模型的实际完成回执；现有 Luna 代测不算生产登录集成。动态教务覆盖、学校写操作、图书馆预约、健康/手机资料及邮件/钉钉发送仍分别需要真实连接和授权，未以模拟成功填补。
