## 已集成的学生生活入口

- **记事本**：桌面 `NotesPanel` 与聊天工具 `manage_note`。原文、全文搜索、分页、编辑冲突、历史版本、撤销及回收站独立于日历和人物记忆；保存想法不会自动排时段。原验收通过“更多 → 记事本”进入。
- **角色**：设置中的 `PersonaEditor`。原创预设、自定义与祥子/睦演绎支持例句预览、编辑、保存、恢复及纯角色模板导入导出；导入预览可先修改再放进草稿，保存才生效。关闭个性记忆仍保留显式角色；例句不是实时模型结果。原验收使用“连接与偏好 → 偏好”。
- **持续托付**：`manage_attention` 保存用户明确的范围、来源、期限和停止条件。来源变化、尚未关联的新变化与已知时间节点进入同一主模型判断；模型可准备、等待、询问、提示或结束。角色不扩大权限。
- **规划**：`situation.read` 按真实来源范围读取有界当前状态；日程实例保留原 UTC，同时提供声明时区的明确本地开始/结束，未知结束不补造。`planning.preview` 计算冲突和未知条件。邀请、愿望、未接受方案不占用已接受承诺，也不自动建立提醒。修改方案绑定原对象版本，点击接受后修改同一对象；撤销恢复原版本内容并产生新修订。
- **出行与天气**：现有公共校园步行图提供路线材料、地图版本和起点质量。没有设备位置时可用明确手动起点。`weather.lookup` 支持杭州、紫金港公开参考点或明确公开坐标及时间窗，区分日级与小时覆盖；WeatherScene 仍是日级展示。预测不是现场观测。

涉及模型的交互沿同一主 Hermes 循环运行；记事本和角色编辑器的普通本地操作直接走宿主业务入口，无需模型。两者共用宿主权限和持久状态。场景和时间线用于验收语义判断，没有作为生产主题分支或关键词通知表。下表保留本次学生 Harness 需要持续遵守的集成点，通用机制详见架构文档。

## 迁移与回退

笔记增加 `h_notes`、`h_note_versions`、`h_note_operations`，复用现有 SQLite 事务和 outbox。旧业务对象不补造来源、发生时间或授权；没有 planning 元数据的旧日程保持原先已登记/固定语义。新笔记中的主体与有效时间默认未知，内容不会自动生成身份判断。

本轮数据库 schema v6 增加 `h_source_restriction_spans` 和 `h_memory_recovery`，分别保存更正范围定位与恢复尝试，不另存一份私人正文。旧更正缺失范围时保留明确未知，不能编造位置。旧版程序不理解较新 schema，不应直接打开升级后的数据库；升级、回退和恢复继续遵守当前隐私屏障。

人格惰性迁移保留五轴设置；旧 guidance 原文保存在私有 `legacy-private-guidance`。确定的纯风格可迁入角色，混合内容不自动迁入预览或导出。角色和导入使用预期版本，恢复会生成新修订，不覆盖后来的修改。

## T8：手机与外部连接的实际边界

当前没有 Android 工程、手机同步 API 或已部署持续宿主。原验收环境检查未发现 PATH 中的 adb、Android 环境变量或标准 SDK 目录，因此没有宣称真机通知、定位、锁屏和进程终止恢复通过。Windows 定位仍明确 `phoneConnected:false`。5173/5174/4173 是本机开发/公共地图端口，Luna 的随机 loopback 端口只服务单次模型传输，均不是手机同步接口。

现有接缝包括 ClockPort、DeliveryPort、Node SQLite、模型/工具回调与 Hermes Python stdio。可行的后续拓扑是 Android 承担本机提醒、通知、授权定位和离线起点，用户选定的持续宿主运行同一 Node/Hermes/数据层，按事件、版本、owner 和 fence 同步；这只是可行性结果，尚未部署。手机本地 Hermes 还需独立证明 Node/Python/SQLite/原生模块与后台生命周期。

Android [WorkManager 周期任务至少 15 分钟且受系统调度](https://developer.android.com/develop/background-work/background-tasks/persistent/getting-started/define-work)，[精确闹钟](https://developer.android.com/develop/background-work/services/alarms)、[后台前台服务启动](https://developer.android.com/develop/background-work/services/fgs/restrictions-bg-start)、[后台定位](https://developer.android.com/develop/sensors-and-location/location/permissions/background)、[通知权限](https://developer.android.com/develop/ui/compose/notifications/notification-permission)各有自身条件。后续需在真实 APK 上分别操作授权/拒绝、退后台/锁屏、离线重连、普通进程终止、force-stop 后重新启动和设备重启，不能承诺 force-stop 后继续后台执行。

[官方 ChatGPT app-server 登录路线](https://developers.openai.com/siwc/token-sharing-open-source/codex-app-server)要求应用自己的授权、令牌续期与撤销，以及所选模型的实际完成回执；现有 Luna 代测不算生产登录集成。动态教务覆盖、学校写操作、图书馆预约、健康/手机资料及邮件/钉钉发送仍分别需要真实连接和授权，未以模拟成功填补。
