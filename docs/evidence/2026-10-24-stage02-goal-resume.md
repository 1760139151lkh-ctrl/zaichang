# 第二阶段：教务、体艺数据与私人运动地图

本轮沿目标文件从第一阶段继续，第二阶段由全新八路实现，主代理分轮审查源码、实际学校响应和集成界面。下列记录只覆盖本次实际取得的证据；十二阶段总目标尚未完成。个人原响应、账号、成绩数值与对话全文保留在仓库外，不随源码发布。

## 教务与自然对话

教务连接器已作为应用运行源码分发，保留上游许可、固定提交和文件修订清单；没有复制个人数据库、账号或技能的运行档案。默认优先使用应用资源及随包 Python，兼容显式选择的旧连接器。已从工作区外、移除 Codex/开发路径覆盖的独立资源目录完成真实读取。

原课程分页、考试对象与无时间文字的课程原行分开保留；缺少时间不推断学校未公布或没有考试。五分制、4.3 换算、四分封顶和主修分别沿原算法、计入条件与学分分母读取。四种修读选择保留原标识，另提供中文名称及选择规则；“来源首条”不冒充第一次修读，“最高成绩”按同一次修读带入各制式，不能分别挑取最高换算值。

主代理实际请求祥子陪看总绩点、主修和本学期考试缺时刻的课程。她分清两种统计范围和分母，没有把课程缺时间当作确定考试，也没有设目标或改日程。后续重新编译当前源码再问四种口径，回复已用中文说明，并明确重修示例不是用户的实际成绩。当前真实记录没有重修组，不宣称已取得此账号的重修实样。

另附的[校方2022年办法](https://meetc.zju.edu.cn/2024/0306/c79045a2885825/page.htm)是公开政策参考，不是个人快照的学校接口采集字段。主代理已核原文第十三、十四条：校内均绩与出国成绩单对重复修读的取法不同，学院评价也可另设权重；本轮未证明该文是最新修订或适用于本人的正式排名用途。原快照仍明确标作 Celechron 衍生分析。

窄刷新仍会解密并重新归一化完整旧学业包；本轮没有绕过用途门。被用途核验拒绝的刷新未执行，实际对话转用合法的同身份保存快照，并说明各来源采集时刻。此限制保留，不能把本机快照说成当次实时校务核验。

## 体艺十九项

保留 HTTPS 统一认证、官方 HTTP 业务直连与场馆两步登录。数据模块复用同一 Connection、认证与加密原响应；没有执行网页脚本、预约、支付、签到或反馈提交。当前及历史学期沿学校实际给出的选项查询。

| 入口 | 已取得的数据层或明确状态 |
| --- | --- |
| 修学记录 | 正式记录表明确空态 |
| 课外锻炼 | 本人运动流水与同快照续页 |
| 活动预告 | 通知及预告接口；预告可续页 |
| 运动队 | 队伍目录、本人队伍权限不足状态及本人考勤查询 |
| 西迁活动 | 活动及本人汇总请求；空对象未补零 |
| 辅导站 | 当前/历史学期及学校续页；空首表与空末页分开 |
| 次数查询 | 当前/历史学期真实表单查询与明确空表 |
| 场馆服务 | 场馆目录、时段、本人订单及本人资料 |
| 身体素质课考勤 | 本人当前课程列表明确空态，不扩成全历史结论 |
| 培训课程 | 学校培训目录，不冒充本人已报名 |
| 体测 | 年度成绩、已有预约与本人反馈 |
| 我的比赛 | 本人报名、成绩、证书及反馈页明确空态 |
| 上课考勤 | 本人课程及所选课程逐次出勤 |
| 场馆出入记录 | 所选当前/历史学期查询与空态 |
| 意见反馈 | 官方声明接口返回 404，未取得本人记录 |
| 场地实况 | 校方人数接口，属于公共场地实况 |
| 体测与锻炼课 | 所选学期课程区明确空态，不推断毕业达标 |
| 毕业体艺报告 | 仅取得封面/底图；本人正文未取得，公布状态未知 |

意见反馈、报告与咕咚未取得正文的调查保留真实限制。意见反馈已核官方脚本指定的地址、请求方式、头部和登录状态；报告已核页面脚本、装饰图片与原生 WebView 接入；咕咚已核原生入口、本人资料和独立 OAuth 路径。没有用入口页或 HTTP 成功码充作记录已读，也没有猜测绑定、毕业或公布状态。

本人查询到数据层后返回明确空列表仍是完成读取，空结果另记 `no_records`；公共目录/人数、权限不足、服务错误和未知报告各自表明覆盖。学校下一页是新观察，保存续页固定原快照与查询条件。显式空快照地址不会退回新查询。原个人资料标记贯穿保存页，姓名、身份与生日等敏感叶地址由宿主拒绝；公共场地名称和 ID 保持可读。

主代理真实对话读到了体测项目/总分，也发现单独次数表与运动统计不同，未把空表当作零次。重新编译最终字段说明后，再问本学期有效锻炼与单独次数表，祥子已用中文分别说明两个结果、统计窗口和读取时间，没有念出内部字段名，也没有业务写入。归档官方客户端 2.9.6 的统计界面与请求参数对应，支持“有效/无效”标签；另一个审核字段的“待审”没有被套给尚未核明的统计状态。

## 运动 owner、时间与地图

运动仍归原 `WorkoutSessionKernel`，原始位置、测量时间、因果滤波、地图候选与学校计次分开。地图由桌面组合入口附加私人运动层，复用共享地图原相机与投影；公共 review 直接导入共享 `CampusMap`，不导入私人运动组件、IPC 或状态。

实际 Android 原生模拟流已检查精确点、弱信号点、暂停/重开恢复及来源切换。独立桌面 profile 的同一 iOS 录制会话，沿公开东田径场参考线经原生 CoreLocation 模拟流累计出超过一公里，取得真实公里分段；没有直接拼入 `WorkoutTrackPoint` 或把模拟定位标作真人跑步。

主代理在集成窗口亲见完整暖金轨迹与首公里微标，实际拖动、查看轨迹、展开分段、切空间视图、返回首页并恢复原对话。轨迹和微标随原相机移动，空间变换后仍贴合。首公里约 2 分 31 秒与全程平均约 13 分 25 秒分别显示；后者包含为调查而持续开着录制的时间，不能互相替换。原会话结束后保留加密记录，原生端回读同一身份的零监听、零缓冲。

实际睦对话在位置持续到达时完成，读出东田径场附近、约 1.77 公里及首公里用时，没有坐标或设备身份。原回复仍保留较长的模拟来源解释，未过滤正文或宣称语气已被形式化保证。有限摘要保留当前/暂停/结束状态与新鲜度，地点是校内语义候选，400 米校方名义标准与 OSM 参考环线分开。

跨设备调查发现宿主与手机时钟相差约六秒。原始测量时间未改，另用同次原生命令与回执形成有界时钟关系；慢通信、墙钟跳变、旧命令和进程变化不被当作新证据。原未来/过期门槛保留，时钟证据冲突会断段，弱信号线也不能跨过该断段。地图和摘要共用测量年龄规则。精确命令处理回执新版桥的最终 Kernel 短流与取消清层仍在复核。
